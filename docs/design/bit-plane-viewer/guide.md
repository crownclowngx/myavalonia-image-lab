# 位平面观察器使用指南

## 产品闭环

选择一张 PNG/JPEG 后点击“分析”。Document 只解码一次原始未预乘 RGBA8888；切换 R/G/B/Alpha/Y 时复用
原图，只替换一份当前通道 `BytePlane` 和八行统计。点击位行改变单位平面的焦点，勾选框改变组合掩码，二者互不
替代。全部、清空、仅高位和仅低位最终都归一为一个 0–255 掩码。

四个预览共享同一最近邻源坐标：原图、焦点单位平面、组合通道和掩码重建。最大边为 1024，小图不放大；拆位发生
在原始字节上，而不是先缩放再拆位。点击任一预览会报告原图坐标、RGBA、当前通道字节、8 位二进制、掩码与保留值。

## 显示与重建语义

- 单位平面：0 是不透明黑，1 是不透明白；观察 Alpha 时也不会因透明而消失。
- 组合通道：显示 `channel & mask` 的真实灰度，不把 bit 0 的最大值 1 拉伸为 255。
- R/G/B：只替换选定颜色字节，另外两个颜色和 Alpha 不变。
- Alpha：只替换 Alpha；全透明像素下的隐藏 RGB 保持。重建面板可显示棋盘背景。
- Y：按 BT.601 全范围公式和中点取偶量化，再保留源 Cb/Cr 与 Alpha 逆变换；界面报告裁切数。
- 全掩码 `0xFF`：五通道均使用逐字节恒等结果，避免 Y 量化往返产生无意义误差。

导出仅支持当前通道和掩码的原始尺寸 PNG。用例按需创建完整重建与编码缓冲，通过既有原子写入端口发布；Document
不长期缓存第二张完整图片。JPEG 不可选，因为有损重编码会改写正在观察的低位。

## 生命周期与资源

源图片上限沿用 64 MiB 编码文件和 16,000,000 像素。每个 Document Scope 长期最多拥有一张完整 RGBA 原图、
一份当前通道 byte 数组和四张最大边 1024 的 RGBA 代理。换图、关闭或 Dispose 会取消分析/投影/导出、推进 generation、
切断 Session 引用并释放旧 Bitmap；掩码变化有 100 ms 防抖，迟到投影不能覆盖当前状态。

快照 schema 为 1，只保存路径、通道、焦点位、掩码、预设边界、说明开关和探针坐标。恢复不会自动读取文件，必须由
用户显式点击“分析”。未知 schema/通道/位/掩码回退到 Y、bit 7、`0x80`。

## 限制

二元熵只描述 0/1 比例，不描述空间结构，也不是隐写概率。本能力不写入或提取秘密、不扫描目录、不做卡方/RS/SPA、
不处理 RAW/HDR/高位深、不使用 AIFLOW，也不登记 Workflow Action、Workbench Command 或 Tool。
