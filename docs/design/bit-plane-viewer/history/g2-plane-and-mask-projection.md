# G2 位平面与掩码投影

状态：完成（2026-08-30）。

实际新增统一 `BitPlanePreviewMap` 与 `BitPlaneProjector`，从原始通道样本直接生成原图、单位平面、组合通道和重建代理。
最大边固定 1024，小图不放大；四张图共用同一源坐标表。单位平面 Alpha 固定 255，组合灰度不归一化。

设计思路：映射表承担坐标责任，投影器承担显示缓冲责任；Document 不参与逐像素循环。没有缓存八张位图，也没有为不同
掩码创建策略对象。快速掩码变化由 Feature 层 100 ms 防抖与 CancellationToken 控制。

证据：`0x80/0x0F/0xF0/0x55/0xAA`、bit 0 最大灰度 1、Alpha 不透明、1024 边界和 Uniform 黑边均有确定断言。
结构预算为四张最大约 1024²×4 的代理；未做机器相关时间阈值。
