# G3 重建、探针与 PNG 导出

状态：完成（2026-08-30）。

实际完成 R/G/B/Alpha/Y 重建、Y 裁切计数、像素探针和完整尺寸 PNG 导出。RGB/Alpha 只替换选中分量；Y 保留
源 Cb/Cr 与 Alpha；探针返回原始 RGBA、通道 byte、二进制、掩码和 kept。导出接口固定 PNG 并使用既有原子写入端口。

设计思路：重建器只产生领域结果，导出用例才负责编码与文件发布，满足 DIP；探针保持 O(1)，不会重新扫描。没有暴露
JPEG 参数，也没有把完整重建缓存进 Document。

证据：未选通道不变、隐藏 RGB、五通道全掩码恒等、源图不变、PNG 格式固定和原子端口均有测试。Y 裁切是报告而非
失败。导出峰值仍可能同时持有源图、完整重建和 PNG byte[]；正式大图性能观察延期到人工/发布阶段。
