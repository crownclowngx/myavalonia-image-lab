# G0 产品与位语义基线

状态：完成（2026-08-30）。

实际冻结了五通道、bit 7 到 bit 0、0/1 黑白显示、真实量级组合、四类掩码预设、BT.601 Y 中点取偶、Alpha
不参与 Y、先拆位后取样、完整 PNG 导出与“不作隐写判断”的边界。`0xFF` 对五通道定义为逐字节恒等，Y 使用捷径
避免 byte 量化往返误差。

设计思路：先把数值协议集中在小值对象和共享颜色原语，再允许 UI 绑定；SOLID 的核心是让产品语义不依赖 Avalonia。
没有建立算法注册中心或通用位深框架，因为 V1 只需要固定 8 位事实。

证据：Golden 测试覆盖关键字节、非法位和黑白/RGB/Y 样本。性能未写毫秒承诺；内存基线继续沿用 16 MP 与 64 MiB。
偏差与风险：有限人工清单尚未执行。回滚时可移除 BitPlanes 目录，不应回退共享 YCbCr 之前先跑既有颜色回归。
