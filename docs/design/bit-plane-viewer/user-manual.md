# 位平面观察器新手使用说明

一个 8 位通道值可以想成八个开关。bit 7 是最重的开关，权重 128；bit 0 是最轻的开关，权重 1。例如
`170 = 0b10101010 = 128 + 32 + 8 + 2`。

1. 点击“选择图片”，选择 PNG 或 JPEG，再点“分析”。JPEG 显示的是解码后像素，不是 JPEG 文件字节或 DCT 系数。
2. 选择 R、G、B、Alpha 或 Y。Y 是按人眼亮度权重计算并量化后的 8 位值。
3. 点击某个 bit 行，右上单位平面会用白色显示该位为 1 的像素，用黑色显示 0。
4. 勾选多个 bit，左下组合图显示这些位实际相加后的灰度；右下显示把未勾选位清零后的原通道重建。
5. “仅高位”适合观察轮廓和主要色阶；“仅低位”适合观察细小数值变化。“清空”是合法状态，不是错误。
6. 点击任一预览查看同一原图像素的 RGBA、二进制和掩码结果。
7. 需要保存时点击“导出完整 PNG”。导出尺寸是原图尺寸，不是 1024 预览尺寸。

观察 Alpha 时，单位平面仍是不透明黑白；重建图默认使用棋盘背景帮助识别透明度。完全透明位置的 RGB 不会被清零。

请不要把“低位很乱”或“熵接近 1”直接解释成隐写。自然纹理、传感器噪声、压缩和颜色转换都可能产生相似现象；
本工具提供观察材料，不给出隐写或篡改结论。
