# 位平面观察器数学原理

## 二进制与掩码

对 8 位值 `v` 和 `b ∈ [0,7]`：

```text
bit(v,b) = (v >> b) & 1
weight(b) = 2^b
kept(v,m) = v & m
```

单位掩码是 `1 << b`。仅高位 `keepHigh(min) = (0xFF << min) & 0xFF`；仅低位在 `max < 7` 时是
`(1 << (max + 1)) - 1`，`max=7` 显式为 `0xFF`。组合显示直接使用 `kept`，不归一化。

## Y 量化与重建

```text
Y = 0.299R + 0.587G + 0.114B
Ybyte = clamp(round-to-even(Y), 0, 255)
Cb = 128 - 0.168736R - 0.331264G + 0.5B
Cr = 128 + 0.5R - 0.418688G - 0.081312B
```

位运算作用于 `Ybyte`。重建把 `targetY = Ybyte & mask` 与源 Cb/Cr 组合：

```text
R' = targetY + 1.402(Cr - 128)
G' = targetY - 0.344136(Cb - 128) - 0.714136(Cr - 128)
B' = targetY + 1.772(Cb - 128)
```

RGB 采用中点取偶并裁切到 byte；任一颜色分量越界则该像素计入裁切数。Alpha 不进入换算。`mask=0xFF` 使用源像素
逐字节恒等捷径，因为 Y 的 byte 量化本身已丢失小数，完整保留不应引入一次新的颜色往返。

## 二元熵

若某位为 1 的比例为 `p`：

```text
H(p) = -p log2(p) - (1-p) log2(1-p)
```

`p=0` 或 `p=1` 时对应项定义为 0；`p=0.5` 时熵为 1。熵不包含像素空间位置，因此棋盘、随机点和大块分区只要
0/1 比例相同就可能具有相同熵。它不能单独作为隐写检测结论。

## 有界预览

设最大边比例 `s = min(1, 1024 / max(width,height))`，预览尺寸按最近整数计算。预览坐标使用端点对齐的最近邻：
`round(x' × (sourceWidth-1) / (previewWidth-1))`，高度同理；单像素边显式映射到 0。四个预览共用同一映射表，
因此预览四角对应原图四角，探针坐标也保持一致。
