# 感知指纹数学原理

## 视觉归一化

RGBA 按未预乘通道解释，先合成到固定白底：`Cvisual = (A/255)×C + (1-A/255)×255`，再计算 BT.601 全范围亮度 `Y=0.299R+0.587G+0.114B`。缩小时采用覆盖面积加权，放大时采用像素中心对齐双线性插值。算法允许非等比拉伸，不补边、不裁剪。该完整协议 ID 为 `fingerprint-luma-bt601-white-matte-area-bilinear-v1`。

## 位序与距离

三种算法都输出 8×8、64 位。左上角对应 bit 63，右下角对应 bit 0；摘要使用大写 `X16`。同算法距离为 `PopCount(A XOR B)`，位相似度为 `100×(64-distance)/64`。

## aHash 与 dHash

aHash 把 8×8 的 64 个值与算术平均比较，固定使用 `value >= mean`，所以均匀图为全 1。dHash 把 9×8 每行的相邻值比较，固定使用 `left > right`，相等写 0。两个比较符号都是兼容性协议，不能静默更改。

## pHash

pHash 对 32×32 亮度做正交二维 DCT-II：

`F(u,v)=α(u)α(v)ΣxΣy f(x,y)cos((2x+1)uπ/64)cos((2y+1)vπ/64)`，其中 `α(0)=1/√32`，其余为 `√(2/32)`。

实现只计算左上 8×8。阈值取排除 DC 后 63 个 AC 系数排序索引 31；64 个系数都使用 `>= median` 输出位，因此 DC 位仍保留。输入不减 128；既有水印 `Dct8x8Transform` 的减 128 语义没有改变。

## 参考策略

`fingerprint-reference-policy-v1` 的 aHash/dHash/pHash 阈值分别为 8/12/12。自动校准清单覆盖确定性纹理图的 0.75 缩放、轻度亮度和反相负样本，证明参考样本位于阈值预期侧；这不是自然图像总体统计，也不构成概率模型。
