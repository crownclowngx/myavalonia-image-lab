# 感知指纹新手使用说明书

感知指纹适合回答：“这两张图虽然尺寸或编码不同，看起来是否仍有相近的粗略结构？”它不能证明两张图来自同一文件、同一作者或同一来源。

先选择两张图片并点击“计算指纹”。距离范围是 0–64：越小表示对应算法的位越接近。位相似度只是把距离换成百分比，便于阅读，不是概率。三个算法可能意见不同；出现“结果分歧”时，应同时查看图片、位图和限制，不要只挑最有利的一行。

aHash 看整体亮暗，速度快但平坦图容易碰撞；dHash 看水平方向明暗变化，垂直结构可能表达不足；pHash 看低频结构，通常更能容忍缩放或 JPEG，但仍怕裁剪、旋转、镜像和局部重排。

“稳定性试验”只在内存中改变参考图，不覆盖原文件。JPEG 不支持透明输入；中心裁剪不做自动对齐。导出的报告只包含文件名、尺寸、算法版本和数值，不包含绝对路径、图片像素或 EXIF。
