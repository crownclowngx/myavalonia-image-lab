# 感知指纹使用指南

## 基本流程

1. 打开“感知指纹”，分别选择参考图 A 和候选图 B。
2. 点击“计算指纹”。应用顺序解码两图；图片尺寸可以不同。
3. 查看 aHash、dHash、pHash 的 A/B 十六进制摘要、距离、位相似度和独立结论。
4. 选择算法行，核对 A、B、XOR 三张 8×8 位图和算法限制。
5. 如需观察参考图稳定性，选择缩放、JPEG、亮度或中心裁剪，输入逗号分隔的 1–21 个强度点后串行运行。
6. 复制人类可读摘要，或原子导出 schema 1 JSON。

任一路径改变都会取消当前任务、释放 Session 并使旧报告失效。“交换 A/B”会交换角色并重新计算；汉明距离应保持对称，但文件名和预览角色会交换。快照只恢复路径和轻量界面参数，不会自动读取磁盘。

## 三种算法

| 算法 | 稳定 ID | 输入 | 观察内容 | V1 参考阈值 |
| --- | --- | --- | --- | --- |
| aHash | `ahash-8x8-mean64-luma-v1` | 8×8 | 相对平均亮暗布局 | ≤ 8 |
| dHash | `dhash-horizontal-9x8-64-luma-v1` | 9×8 | 水平相邻亮度梯度 | ≤ 12 |
| pHash | `phash-dct32-low8-median64-luma-v1` | 32×32→低频 8×8 | 低频 DCT 结构 | ≤ 12 |

距离 0 只说明该算法的 64 位摘要相同。阈值来自离线可重复参考清单，只是解释线，不适用于所有图像分布。总览不平均三个百分比，只显示一致接近、结果分歧、一致不接近或结果不完整。

## 稳定性参数

- 缩放：长宽同比例 `0.1–1.0`。
- JPEG：整数质量 `40–100`；含透明像素图片会明确阻断。
- 亮度：`-20%–+20%`，复用既有亮度算子且保持 Alpha。
- 中心裁剪：每边 `0–10%`；不做几何配准，距离上升属于预期现象。

每次只运行一个轴，最多 21 点，不缓存所有完整样本。界面只保留当前样本预览；报告保存点事实，不保存图片或编码字节。

## Robustness Lab 观测

鲁棒性实验室可选勾选 aHash、dHash、pHash。它比较每个 Profile 的未扰动水印基线与最终案例图，只向 JSON/CSV 追加摘要和距离；不会改变水印成功、BER、质量 N/A 或失败分类。
