# 图像比较实验室的数学原理

本文解释 V1 报告中的差值、误差、PSNR、全局 SSIM-Y 和直方图。公式中的参考图记作 `R`，待比较图记作 `C`；图片共有 `N` 个像素。

## 1. 逐像素差值

每个颜色通道的有符号差固定为：

```text
Δ = C - R
```

所以交换两张图后，`Δ` 的正负号反向，但绝对误差、MSE、PSNR 和对称的 SSIM 不变。RGB 差异图使用绝对值并乘显示倍率：

```text
display = clamp(|C-R| × gain, 0, 255)
```

倍率只是为了让微小差异更容易看见，不参与完整图片指标。

## 2. MAE、MSE 和 RMSE

对 RGB 共 `3N` 个样本：

```text
MAE  = (1/3N) Σ |C-R|
MSE  = (1/3N) Σ (C-R)²
RMSE = sqrt(MSE)
```

MAE 容易直观理解为“平均差几个灰度级”。MSE 对大误差平方，因此更重视少数明显错误。RMSE 把单位还原到和颜色值相同，但仍保留 MSE 对大误差的敏感性。

最大差异是全部 RGB 样本中最大的 `|C-R|`。变化像素比例则按像素计数：只要某个位置的 R、G、B 至少一个不同，该像素就记为变化。

## 3. PSNR

8-bit 通道的峰值 `MAX` 为 255：

```text
PSNR = 10 log10(MAX² / MSE)
```

单位为 dB。MSE 越小，PSNR 越大；MSE 为 0 时两图在对应样本上完全一致，PSNR 按定义趋向正无穷，所以界面显示 `∞`，JSON 使用合法的空值加 `isInfinite` 标记。

V1 的 `PSNR-RGB` 使用 `3N` 个 RGB 样本；`PSNR-Y` 先把每个像素转换为 Y，再用 `N` 个样本。不同软件若使用不同色彩公式、范围或 Alpha 处理，数值不能直接横向比较。

## 4. Y、Cb、Cr

`Y` 近似亮度，`Cb/Cr` 表示两类色差。实现使用冻结公式并把结果四舍五入、裁切到 0–255，确保直方图和指标可复现。

Y 并不是物理测光意义上的绝对亮度，也不包含 Alpha。完全透明像素内部的 RGB 仍参与换算，这是 V1 明确语义。

## 5. 全局 SSIM-Y

结构相似度把亮度均值、对比度和共同变化综合在一个式子里。当前实现对整幅 Y 通道计算一个全局值：

```text
SSIM = ((2μRμC + C1)(2σRC + C2))
       / ((μR² + μC² + C1)(σR² + σC² + C2))
```

`μR/μC` 是两图 Y 均值，`σR²/σC²` 是样本方差，`σRC` 是协方差，`C1/C2` 防止分母在近常量图片上接近零。完全一致时为 1。

常见论文或工具经常在 11×11 局部窗口计算 SSIM Map 后再平均。V1 不是这种局部 SSIM，因此即使名字相同，结果也不能当作同一算法的数值互换。

## 6. 直方图

对通道 `k` 的 256-bin 直方图：

```text
h[k] = 取值恰为 k 的像素数量
Σ(k=0..255) h[k] = N
```

直方图只统计“每种值出现多少次”，不保存“出现在哪里”。将一张图的像素随机打乱，直方图可以完全不变，但空间结构已经消失。因此直方图相似不能证明图片相同。

显示纵轴可使用 `log10(count+1)`，让数量差异很大的 bin 同时可见。加 1 是为了让计数 0 也有定义；原始导出仍保存整数计数。

## 7. 热力图与固定映射

热力图先为每个像素计算 MaxRGB 或 Y 的绝对差，再用固定的 256 色表映射颜色。固定映射意味着同一个差值在不同图片上始终使用同一种颜色，便于横向比较。它不会针对每一对图片自动拉伸，所以非常小的差异可能集中在色表低端。

## 8. 为什么必须同尺寸

所有上述公式都假定 `R(x,y)` 与 `C(x,y)` 描述同一个坐标。自动缩放、裁切或对齐会引入新的插值和几何假设，导致误差同时混合“原始变化”和“工具做的变换”。V1 在尺寸不同时明确停止指标计算，避免生成数学上有数值、语义上却不可信的结果。

## 9. 指标不能提供通用合格线

同一个 PSNR 对照片压缩、科学图像、UI 截图和医学影像的意义不同。高 PSNR 也可能掩盖一个很小但关键的局部错误；直方图一致也可能完全错位。正确做法是结合任务定义、视觉定位、像素检查和多个指标建立领域自己的验收阈值。
