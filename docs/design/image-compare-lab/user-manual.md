# 图像比较实验室新手使用说明书

## 它能回答什么

当两张图片看起来几乎一样时，人眼可能很难判断哪里变了。图像比较实验室把第一张图片当作“参考答案”，把第二张当作“待比较结果”，逐个位置检查颜色差异，并用图像、数字和直方图呈现。

它不会替你决定哪张更好，也不会自动判断图片是否被篡改。它只提供可核对的差异事实。

## 三个基础概念

- **参考图**：作为比较基准的第一张图片。
- **待比较图**：需要检查的第二张图片。
- **同尺寸**：两张图的宽度和高度必须完全相同，才能让每个像素一一对应。

文件名、扩展名或文件大小相同都不代表图片像素相同；反过来，PNG 和 JPEG 文件字节不同，也可能解码出非常接近的画面。

## 第一次比较

1. 打开“图像比较实验室”。
2. 选择参考图，再选择待比较图。
3. 点击“比较”。
4. 如果尺寸不同，先在外部确认为什么不同。本工具不会悄悄缩放、裁切或对齐。
5. 尺寸相同时，先看“并排”，用滚轮同步缩放、右键拖动平移。
6. 再切换“热力图”或“RGB 差异”，寻找变化集中的位置。
7. 把指针移到可疑位置，读取两边像素和差值。
8. 需要留档时，复制文字摘要或导出 JSON。

## 六种视图该什么时候用

| 模式 | 最适合观察 |
| --- | --- |
| 并排 | 整体构图、颜色和清晰度差异 |
| 分割 | 同一位置左右切换，查看边界是否对齐 |
| 叠加 | 轮廓错位、轻微位移和透明变化 |
| 闪烁 | 很细小但分布广的变化；对闪烁敏感者不要使用 |
| RGB 差异 | 红绿蓝绝对差异；倍率只放大显示，不改变原始指标 |
| 热力图 | 快速定位差异强弱，颜色是固定映射，不代表温度 |

“适应”让整张图尽量放进当前面板；“100%”表示显示代理像素一比一。对于大图，界面可能使用代理来显示，但数值指标仍基于完整图片。

## 先学会读四个常用数字

- **变化像素比例**：有多少位置的 RGB 至少一个值不同。越接近 0，变化位置越少。
- **MAE**：平均每个颜色值差多少。0 表示完全一致，越小通常越接近。
- **PSNR**：用分贝表示误差相对有多小。通常越大越接近；完全一致时显示 `∞`。
- **SSIM-Y**：比较整体亮度结构，完全一致时为 1。本工具使用全局版本，不等同于其他软件的局部 SSIM。

这些数值没有适用于所有行业的统一合格线。照片、医学图像、图标、压缩结果和算法输出需要不同标准，应结合任务和样本制定阈值。

## 直方图能看出什么

直方图统计每个亮度或颜色值出现多少次。蓝线代表参考图，橙线代表待比较图。两条线接近，说明整体颜色分布接近；但像素位置可能仍完全不同，所以直方图必须和差异图一起看。

`R/G/B` 是红绿蓝；`Y` 近似明暗；`Cb/Cr` 表示两类颜色差。对初学者，先看 Y 和 RGB 即可。

## 透明图片要特别注意

透明度 Alpha 单独统计，不进入 RGB 质量指标。一个完全透明的位置内部仍可带有 RGB 数值，所以可能出现“肉眼看不见，但 RGB 指标显示有差异”。反过来，仅透明度改变时，RGB 的 PSNR 可能仍是 `∞`。这不是计算错误。

## 遇到问题时

- **没有指标**：先检查两张图是否同尺寸，以及是否已经点击比较。
- **换图后不能导出旧结果**：这是保护机制；路径变化会让旧结果立即失效。
- **差异图几乎全黑**：逐步提高差异倍率，或改看热力图；指标本身不会被倍率改变。
- **交换后差值符号变了**：有符号差按“待比较 − 参考”计算，交换角色后自然反向。
- **闪烁不舒服**：立即暂停并使用分割或叠加模式。
