# 图像比较实验室

这项能力把一张图片作为参考图，把另一张同尺寸图片作为待比较图，通过同步视图、差异图、直方图和客观指标帮助定位变化。

## 建议阅读顺序

- 第一次使用：从 [新手使用说明书](user-manual.md) 开始。
- 查阅视觉模式、指标和 JSON 语义：阅读 [使用指南](guide.md)。
- 理解误差、PSNR、SSIM 与直方图：阅读 [数学原理](mathematical-principles.md)。
- 开发与维护：阅读 [实施计划](implementation.md) 和 [测试门禁](testing.md)。
- 追溯实施过程：查看 [G0–G7 历史记录](history/README.md)。

比较结果只描述两张已解码图片之间的差异，不会自动判断“合格”“篡改”或“视觉上更好”。
