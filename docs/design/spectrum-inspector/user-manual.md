# 频域分析器新手使用说明书

## 从“图片由什么组成”开始

我们平时看到的是图片在每个位置的颜色，这种观察方式叫“空间域”。还可以换一个角度：不问某个位置是什么颜色，而问图片中“变化得有多快”的成分有多少，这就是“频域”。

- 缓慢变化通常属于低频，例如天空的渐变、大片明暗轮廓。
- 快速变化通常属于高频，例如细小文字、毛发、锐利边缘和噪点。
- 中频位于两者之间，常包含纹理和较细的结构。

频域分析器就像把一首音乐分成低音、中音和高音，只不过对象换成了二维图片。

## 第一次分析

1. 打开“频域分析器”。
2. 选择一张 PNG 或 JPEG 图片。
3. 通道先选择 `Y`。Y 近似表示明暗，比单独看红、绿、蓝更容易理解。
4. 分析档位先选择 `512`，它速度快、占用资源少。
5. 点击“分析”。
6. 观察状态栏：原图尺寸是文件本来的大小，分析代理是实际参与本次分析的缩小版本，FFT 尺寸还可能因计算需要补到 2 的幂。

小图不会被放大。大图会生成代理，因此分析结果和导出结果不应被误认为原尺寸处理。

## 怎样看频谱图

先切换到“对数幅度”。频谱中心代表零频率，也叫 DC，主要对应整体平均明暗。离中心越远，代表变化越快。自然图片通常中心更亮，因为大片平缓区域贡献较多。

把指针移到频谱上时，侧栏会显示频率坐标、半径、幅值、相位和能量。初次使用只需记住：

- **幅值**：这个变化规律有多强。
- **能量**：该频率对整幅图的贡献程度。
- **相位**：变化规律在图片中的位置关系；幅值接近零时相位没有可靠意义。
- **cycles/pixel**：每走一个像素，变化完成多少个周期，是频率单位。

“线性幅度”容易被中央强亮点压住；“对数幅度”更适合看弱细节；“P99.5”用稳健上限改善显示，但不改变原始数据。

## 做一个最直观的频带实验

分析完成后依次选择不同频带：

1. 选择“低频”并等待重建。结果通常保留整体轮廓和明暗，细节变柔和。
2. 选择“高频”。结果更突出边缘和细碎变化，大片平滑区域会减弱。
3. 选择“中频”。观察纹理和局部结构。
4. 选择“全部”。它应恢复分析代理本身，而不是原尺寸图片。

这个实验不是在修改源文件。只有主动点击“导出代理 PNG”时才会写出重建结果。

## 六个通道怎么理解

- `R/G/B`：红、绿、蓝三个颜色分量。
- `Y`：近似亮度，适合先观察结构与明暗。
- `Cb/Cr`：蓝色差和红色差，可粗略理解为两种颜色信息。

Alpha（透明度）不进入频率分析。分析 RGB 通道时，完全透明像素内部仍可能保存颜色字节，因此频谱中可能出现肉眼看不见的内容。

## DCT 面板是做什么的

DCT 把图片分成 8×8 小块，观察每块内部由平滑到细节的成分。点击原图预览可查看对应小块的像素、DCT 系数、反变换结果和最大误差。它适合理解 JPEG 和水印为什么常围绕 8×8 块工作。

## 常见误解

- 频谱中的亮点不一定是“问题”，它只说明某种变化规律较强。
- 高频不等于噪声；真实边缘和文字也属于高频。
- 低频不等于模糊；它包含图片最主要的整体结构。
- 只保留某个频带是学习和检查手段，不等于自动增强图片。
- 导出的文件是分析代理尺寸，不是原尺寸无损编辑结果。
