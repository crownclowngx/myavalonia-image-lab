# 频域分析器的数学原理

本文用尽量直观的方式解释 FFT、幅值、相位、频带重建和 8×8 DCT。界面字段与冻结范围以 [使用指南](guide.md) 为准。

## 1. 空间域与频域

在空间域中，函数 `f(x,y)` 表示图片在坐标 `(x,y)` 的一个通道值。频域不直接描述位置，而描述不同水平、垂直变化速度的权重。

二维离散傅里叶变换（DFT）为：

```text
F(u,v) = Σx Σy f(x,y) · exp[-j2π(ux/W + vy/H)]
```

`u` 和 `v` 是水平、垂直频率索引，`j` 是虚数单位。FFT 是高效计算 DFT 的算法，不是一种不同的变换。

## 2. 为什么需要补到 2 的幂

基 2 FFT 在尺寸为 `2^n` 时计算结构最直接。分析代理的宽高分别补零到不小于自身的最小 2 的幂，例如宽 700 会补到 1024。补零不会给原图增加真实细节，但会改变采样网格，并使频谱尺寸与代理尺寸不同。

大图先按面积平均缩成最大边 512、1024 或 2048 的代理。这样限制内存和计算量，所以频域结论对应代理采样，不是原尺寸逐像素处理。

## 3. 复数、幅值和相位

每个频率值 `F(u,v)` 是复数，可写成 `a + jb`。

```text
幅值 |F| = sqrt(a² + b²)
相位 φ = atan2(b, a)
能量 E = |F|²
```

幅值说明某种变化有多强，相位保存这些变化在空间中的相对位置。幅值接近零时，极小误差就能造成很大的相位跳动，所以界面对低能量点显示“未定义”。

自然图片的 DC 和低频幅值可能比其他位置大很多。对数显示使用类似 `log(1+|F|)` 的压缩，把弱成分也显示出来；它只改变可视化尺度，不修改频谱。

## 4. 中心化坐标和 cycles/pixel

FFT 内部通常把 DC 放在数组角落，显示时把它移到中心。中心化坐标 `(kx,ky)` 对应：

```text
fx = kx / W
fy = ky / H
```

单位 `cycles/pixel` 表示每个像素包含多少个变化周期。半径用于按方向无关的距离分组；当前界面把半径归一化后划分低、中、高频。精确边界见 [使用指南](guide.md)。

## 5. 实值图片为什么有对称频谱

输入通道是实数时，频谱满足共轭对称：

```text
F(-u,-v) = conjugate(F(u,v))
```

因此中心两侧常出现成对亮点。重建遮罩必须同时保留或删除一对共轭频率，否则逆变换可能产生不应存在的明显虚部。V1 的频带遮罩按这一约束构造。

## 6. 频带遮罩与逆 FFT

设遮罩 `M(u,v)` 只取 0 或 1，重建频谱为：

```text
G(u,v) = F(u,v) · M(u,v)
g(x,y) = IFFT(G(u,v))
```

低通遮罩保留靠近中心的成分，通常得到平滑轮廓；高通遮罩保留外侧成分，通常突出边缘和细节。环带同时设置内外半径。遮罩边界突然从 1 变 0，空间域可能出现振铃，这是理想硬遮罩的常见现象。

“全部频带”不需要真的做颜色往返和 IFFT，当前实现使用逐字节短路，确保得到分析代理原字节。

## 7. Parseval：空间能量与频域能量守恒

在匹配的归一化约定下，空间域平方和与频域平方和只差一个固定比例：

```text
Σx,y |f(x,y)|² = (1/WH) Σu,v |F(u,v)|²
```

这叫 Parseval 定理。它既能检查 FFT 实现，也允许把频谱能量按半径汇总。界面的 256-bin 径向曲线和 DC/低/中/高占比由此而来；分区占比总和应保持一致。

## 8. DCT 与 FFT 的区别

DCT 使用余弦基并处理 8×8 实值块，常用于 JPEG 和当前水印算法；FFT 使用复指数并观察整个分析代理的周期成分。

二维 DCT 的简化形式是：

```text
C(u,v) = a(u)a(v) Σx Σy f(x,y)
         cos((2x+1)uπ/16) cos((2y+1)vπ/16)
```

块内左上系数代表平均值，越向右下通常越偏高频。IDCT 应把系数恢复回原块；界面显示最大重建误差，帮助观察浮点计算和边缘块处理是否合理。

## 9. 通道变换与裁切

分析 `R/G/B` 时，重建只替换所选字节。分析 `Y/Cb/Cr` 时，需要与另外两个原始色彩分量一起转换回 RGB。逆变换可能得到小于 0 或大于 255 的数值，程序会裁切并报告像素数。裁切属于色彩空间回转的数值结果，不应误解为 FFT 能量凭空消失。
