# Hybrid Image 用户手册

## 输入区

- `A 低频／远看`：参考坐标系、默认输出边界和 Gaussian 低通来源；
- `B 高频／近看`：经 B→A 相似变换、逆向采样和 Gaussian 高通的来源；
- `交换 A/B`：交换角色与控制点端点，随后必须重新准备和求解。

## 控制点区

每行包含 `Id、Ax、Ay、Bx、By`，坐标范围是闭区间 `[0,1]`。点对可以增至 8 对或减至 2 对。输入、点位或裁切变化会推进 generation，并把下游结果标为过期。

两点结果会显示“无法独立验证残差”。三点以上显示实际重投影 RMS/最大残差；低残差只说明控制点数学拟合好，不说明两张图语义上适合混合。

## 结果页

- `输入与重影`：A、B 与红青 Sobel 边缘；
- `分量`：A 低频与 B 有符号高频；
- `四尺度`：同一 raw 的真实 1×/1/2×/1/4×/1/8×像素；
- `频谱`：中心化 raw 频谱。A/B/低/高/raw 的内部投影使用同一显示量程。

## 状态语义

- “尚未求解”：有输入但没有当前对齐；
- “结果已过期”：输入、点位、裁切、σ 或 gain 已改变；
- “代理完成”：可检查交互结果，但不能导出成品 PNG；
- “完整尺寸完成”：候选结果已通过 Session/generation/recipe 三重提交检查；
- “已取消”：最后有效结果保留，取消候选不会部分提交。

## 导出

只有当前完整尺寸结果可以导出 PNG，且目标不能覆盖 A/B。编码后先内存回读，再原子发布并从真实目标回读；灰度、Alpha、尺寸或 RGBA 不一致都会失败。Recipe 和报告可独立导出；报告不包含路径。

## 限制

“远看”由确定性缩小近似，不等于真实视力、观看距离、屏幕点距或环境光。产品不保证每一对图片或每位观察者都发生明显主体切换。
