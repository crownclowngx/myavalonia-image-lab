# Hybrid Image 使用指南

## 最短闭环

1. 选择 A：缩小或远看时希望保留的低频主体。
2. 选择 B：近看时希望更明显的高频主体。
3. 点击“准备双输入”。每张图片只解码一次，并建立最大边 1024 的代理。
4. 用 2–8 对归一化坐标标出同一语义位置。建议至少使用三个分散点；头像可用双眼与嘴角，建筑可用分散角点。
5. 点击“求解 B→A”。检查缩放、旋转、残差、覆盖率和默认裁切。
6. 观察红 A／青 B 边缘。共同强边缘接近白色；内容不同的边缘本来就不会重合。
7. 调节 A 低通 σ、B 高通 σ和两个增益，然后生成代理。
8. 对比 1×、1/2×、1/4×、1/8×。四张图均来自同一未量化 raw，不是控件缩放。
9. 满意后显式执行完整尺寸，再导出 PNG、recipe 或脱敏报告。

## 参数判断

- `LowSigmaPixels` 越大，A 越模糊，保留频率越集中在中心；
- `HighSigmaPixels` 越大，从 B 中减去的低通更宽，B 高频包含更宽的非 DC 频带；
- `LowGain` 或 `HighGain` 为 0 时对应分量被精确消除；两个都为 0 是合法黑图诊断；
- raw 超出 `[0,1]` 时只在最终 PNG 量化阶段裁切，报告会保留上下溢数量与比例；
- 高频分量页的 0.5 中性灰和显示 ×2 只用于观察，不参与结果。

## 对齐建议

- 两点能精确决定相似变换，但没有冗余残差验证；
- 三点以上应覆盖主体不同方向，避免点聚集在一个小区域；
- 透视、表情、非刚性差异不能靠增加控制点变成相似变换；
- 默认有效矩形来自双线性有效掩码，不是变换后 B 的外接框；
- 若边长不足 32 或覆盖 A 少于 10%，应更换点位、图片或变换模型，而不是透明补边。

## 安全与隐私

Recipe 和报告只保存内容指纹、参数与数值事实，不保存绝对路径或像素。快照只保存文件名提示和轻量参数；恢复后必须重新选择 A/B，不会自动访问磁盘或执行计算。
