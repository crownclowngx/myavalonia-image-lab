# 卷积核实验台新手说明书

## 先理解三个词

“核”是一张小数字表。实验台把它的中心放到每个输出像素上，读取附近像素、乘以对应数字，再把所有乘积相加。“边界”决定核伸出图片时去哪里取值。“归一化”决定总和要除以多少。

本产品执行真卷积。矩阵中的 `(kx,ky)` 会读取 `f(x-kx,y-ky)`；这与很多图形库默认的相关运算方向不同。对称核看不出差别，Sobel、浮雕或非对称自定义核可以看出。

## 第一次使用

1. 点击“选择图片”，选择 PNG 或 JPEG，再点击“载入并预览”。
2. 保留默认 `gaussian`、3×3、`Reflect101`、`KernelSum`、`Rgb`。
3. 查看四个面板：代理原图、卷积结果、绝对差异和核频率响应。
4. 改成 `sobel`，把梯度输出切到 `X`、`Y` 或 `Magnitude`。Magnitude 表示两个方向强度的平方和开方。
5. 输入 X/Y 坐标并点击“复算贡献”，核对累加值、除数、偏置、舍入和裁切。
6. 结果满意后点击“完整尺寸”。只有它成功完成且参数没有再变，导出按钮才可用。

## 四种边界

- `Constant`：越界使用你输入的常量，0 表示黑色/零分量。
- `Replicate`：重复最近边缘像素。
- `Reflect101`：以边界外侧镜像，但不重复边缘像素，通常比复制边缘更平滑。
- `Wrap`：从另一侧环绕，适合观察周期信号，但普通照片边缘可能出现接缝。

## 四种归一化

- `None`：除数为 1，保留核本来的增益。
- `KernelSum`：除以所有系数之和，适合均值和 Gaussian；零和边缘核会被阻断。
- `AbsoluteSum`：除以系数绝对值之和，方便控制正负核的显示量级。
- `Explicit`：使用你输入的除数。NaN、Infinity 或接近 0 会在执行前报错。

## 偏置、负响应和裁切

导数核会产生负值，但 PNG 像素只能保存 0..255。偏置 128 可把零响应移到中灰附近。偏置后统一使用 AwayFromZero 舍入，再裁切到 0..255；状态栏会报告低端和高端裁切数量。偏置只是显示/重建选择，不进入频率响应。

## 自定义矩阵

每行用换行分隔；列可用空格、Tab、逗号或分号。数字使用点号小数。所有行列数必须一致，尺寸必须是 3..31 的奇数方阵。编辑矩阵会显式切换为 `custom`；无效草稿会显示具体行列错误，并保留最后已生成结果。

## 常见误解

- 锐化增强局部变化，不会恢复已经丢失的真实细节。
- 边缘图是离散响应，不是物体识别结果。
- 代理结果用于交互观察，不保证等于对完整原图逐像素处理后再缩小。
- 差异小只表示数值接近，不代表处理“更好”。
