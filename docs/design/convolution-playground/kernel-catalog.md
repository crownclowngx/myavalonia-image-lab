# 卷积核目录

显示名可本地化，快照只写稳定 ID。下表的推荐归一化/偏置只是创建预设时的初值，用户随后选择的值不会被后台偷偷覆盖。

| 稳定 ID | 定义 | 推荐 | DC/说明 |
| --- | --- | --- | --- |
| `identity` | 中心 1，其余 0 | None / 0 | DC=1，数值与方向基线 |
| `mean` | K² 个 1 | KernelSum / 0 | 归一化后 DC=1 |
| `gaussian` | `exp(-(x²+y²)/(2σ²))` 后归一 | KernelSum / 0 | 对称、非负、DC=1 |
| `motion` | 中心线段等距采样并双线性栅格化 | KernelSum / 0 | 非负、核和 1；离散权重可见 |
| `sharpen` | `δ + a(4δ-N4)` | None / 0 | 核和 1；增强四邻域变化 |
| `unsharp` | `(1+a)δ-aGσ` | None / 0 | 核和 1；a=0 精确 Identity |
| `high-boost` | `Aδ-Gσ` | None / 0 | DC=A-1 |
| `sobel` | X/Y：`[-1,0,1; -2,0,2; -1,0,1]` 及转置 | None / 0 | 两核均零和；可选 X/Y/Magnitude |
| `prewitt` | X/Y：`[-1,0,1]` 三行及转置 | None / 0 | 零和一阶差分 |
| `scharr` | X/Y：`[-3,0,3; -10,0,10; -3,0,3]` 及转置 | None / 0 | 零和，增强旋转一致性 |
| `laplacian-4` | `[0,1,0;1,-4,1;0,1,0]` | None / 128 | 零和二阶差分 |
| `laplacian-8` | `[1,1,1;1,-8,1;1,1,1]` | None / 128 | 八邻域零和二阶差分 |
| `emboss` | 方向一阶差分矩阵，按有限方向旋转 | None / 128 | 零和；强度 0..5 |
| `custom` | 用户矩阵 | None / 0 | 具体 DC 为核和/有效除数 |

## 方向约定

表中矩阵就是 UI 展示矩阵，并按真卷积 `h(ky,kx)*f(x-kx,y-ky)` 执行。因此常见以相关运算描述的 Sobel 正方向可能与其他软件相反；本产品不翻转显示名称来掩盖差异。用中心 impulse 或横纵 ramp 可以复核方向。

## Motion 离散化

Motion 不声称精确积分无限细的连续线段。实现以与长度确定的样本数沿线取点，再把每点权重双线性分到相邻四格，最后归一化。重复参数严格确定；0° 与 180° 等价，负角度规范化到 `[0,180)`。

## 双核响应

Sobel/Prewitt/Scharr 的 X/Y 是两个独立线性核。Magnitude 在空间域先得到除数后的 Gx/Gy，再计算 `sqrt(Gx²+Gy²)`，最后应用一次偏置。频率面板只显示 `sqrt(|Hx|²+|Hy|²)` 的幅值摘要，不提供虚构相位或等价核。
