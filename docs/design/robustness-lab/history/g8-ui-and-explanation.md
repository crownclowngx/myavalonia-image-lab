# G8 UI 与解释

第五个 View 提供载体/Payload/Profile、可增删启停复制移动的有序步骤、单轴扫描、资源预检、进度/取消、曲线、Profile 矩阵、等价数值表和 JSON/CSV 导出。

曲线与矩阵控件只绘制聚合 DTO，不拥有实验或调用算法；支持键盘焦点/方向键。颜色不是唯一信息来源，下方表格保留 Profile、扫描值、成功率和 n。界面明确解释 BER 层次、质量参考、几何 N/A、确定性随机和隐私边界。Headless 测试加载真实 View 与两个控件。

运行期间增加明确的交互反馈：后台准备基线时使用不确定进度，进入扫描后显示“案例 x/y”的确定进度；配方区暂时锁定，避免运行条件漂移，结果区和取消按钮保持可用。取消后立即显示“正在取消”，并说明计算会在下一个安全检查点结束。
