# 鲁棒性实验室 V1 用户指南

第一次设计鲁棒性实验时，建议先阅读 [新手使用说明书](user-manual.md)；扫描、BER、纠错和质量指标背景见 [数学原理](mathematical-principles.md)。

## 产品用途

鲁棒性实验室用于回答一个受控问题：同一载体、Payload 和水印 Profile 在一条明确的图像扰动链下，恢复结论何时开始失败，失败发生在链的哪个可观察前缀。它不是通用图片编辑器，也不会自动寻找“最强攻击”。

## 操作闭环

1. 在第五个 Persistable Document“鲁棒性实验室”中选择 PNG/JPEG 原始载体。
2. 输入当前实验使用的文本 Payload；可选输入密码。二者只存在于当前 Document 实例，不进入快照或导出报告。
3. 选择隐蔽、均衡、鲁棒中的一个或多个 Profile。
4. 添加扰动步骤。列表顺序就是执行顺序；可启停、复制、删除、上移或下移。
5. 选择一个步骤，再从中文参数下拉框选择扫描参数和基准值；界面会说明单位、范围、强弱方向与建议扫描值。随后设置扫描起点、终点、步长、trial 数和实验种子。
6. 点击“预检”。预检会在读取图片前验证步骤数、扫描点、Profile×点×trial 案例数和分步观察数。
7. 点击“运行”。系统先建立每个 Profile 的未扰动受控基线，并用正式提取链证明 Payload 可完整回读；失败时不会开始扫描。
8. 在曲线、矩阵和等价文字表中查看结果；需要复核时导出 JSON 或 CSV。

界面使用中文攻击名与参数名帮助选择，同时在括号中保留稳定英文 ID，例如 `quality`、`sigma`、`ratio`、`scale-x`、`degrees`、`offset`、`factor`、`gamma`、`dx`、`left` 或 `red`。这些 ID 用于快照、报告和复现实验，不要求用户手工输入。参数不受支持时预检会明确阻断，不会静默忽略。

## 指标解释

- “成功”同时要求：正式 V1 水印被支持、Payload 完整恢复、恢复内容与基线逐字节相等、完整性为 `Valid`。
- `PhysicalRawBer` 是每个实际 QIM 副本在投票前的 bit 错误率。
- `VotedPreEccBer` 是加权副本投票后、Reed-Solomon 纠错前的 bit 错误率。
- Header/Data 的 BER、平均置信度、P10 置信度和 RS 修复数分开保存。RS 为 0 不代表物理信道没有错误，错误可能已被副本投票消除。
- `AttackOnlyQuality` 以未扰动水印基线为参考；`EndToEndQuality` 以原始载体为参考。
- 尺寸不同会显示 `N/A/SizeMismatch`，不会被当作 0，也不会偷偷缩放回原尺寸。
- “首次失败”只是第一个失败的链前缀观察，不证明该算子单独必然导致失败。后续步骤偶然恢复时会标记 `RecoveredAfterFailure`。
- 16×16 局部网格是 RGB/Y 误差统计，不是局部 SSIM Map。

## 随机性、隐私与限制

噪声使用实验专用 SHA-256/SplitMix64-v1 子种子。相同输入像素、配方、种子和实现版本可重现；JPEG 跨不同后端不承诺像素完全一致。实验随机源绝不替代水印协议的 salt、nonce、Mapping Key 等密码学随机源。

快照不保存内联 Payload、密码、像素、结果或密钥；恢复后必须重新输入敏感值并显式运行。JSON/CSV 只保留载体文件名，不包含绝对路径、Payload 内容、恢复内容、密码、salt、nonce、Mapping Key 或异常堆栈。

V1 不做自动几何配准、多参数笛卡尔积、自动攻击搜索、脚本/反射算子、后台并行队列、AIFLOW、外部水印图 BER 推断或通用格式转换。结论是当前受控样本的实验事实，不是对任意图片或平台的“不可破坏”承诺。
