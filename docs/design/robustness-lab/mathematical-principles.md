# 鲁棒性实验室的数学原理

本文解释单参数扫描、成功率、BER、置信度、纠错与质量指标之间的关系。它帮助正确解释实验，不提供“不可破坏”的证明。

## 1. 受控实验与变量

一次实验应区分：

- **自变量**：主动改变的参数，例如 JPEG `quality` 或噪声 `sigma`。
- **因变量**：观察结果，例如是否成功恢复、BER 或 PSNR。
- **控制变量**：保持不变的载体、Payload、Profile、其他步骤参数、种子和实现版本。

V1 只扫描一个参数。若同时改变多个参数，就很难判断结果变化由谁造成；完整多参数笛卡尔积也会迅速放大案例数量。

## 2. 扫描点和案例数

等步长扫描可写成：

```text
x_i = start + i · step
```

实现使用十进制参数并显式处理端点，减少浮点累加导致“理论终点没有被取到”的问题。

总案例数大致为：

```text
案例数 = Profile 数 × 扫描点数 × trial 数
```

如果还记录扰动链的每个前缀，观察次数会继续乘以需要检查的前缀数量。预检对案例和观察总数设上限，以控制时间和内存。

## 3. 成功率是样本比例

在同一参数点运行 `n` 次，其中 `s` 次完整成功：

```text
成功率 p_hat = s / n
```

当扰动完全确定且所有条件相同，重复 trial 通常不会提供新信息；对噪声等随机扰动，多次 trial 才能估计成功概率。`1/1` 只能说明一次样本成功，不能等同于真实成功概率为 100%。

若把每次结果近似看作独立伯努利试验，标准误差约为：

```text
SE ≈ sqrt(p_hat(1-p_hat)/n)
```

样本少或成功率恰为 0/1 时，这个近似并不稳健；正式研究可使用 Wilson 区间并增加样本数。V1 报告保存原始案例，使外部工具能够做进一步统计。

## 4. BER：bit 错误率

若预期 bit 序列为 `b_i`，读取序列为 `r_i`：

```text
BER = (1/L) Σ [b_i ≠ r_i]
```

其中方括号在条件成立时为 1，否则为 0。

- `PhysicalRawBer`：每个 QIM 物理副本投票前的错误率。
- `VotedPreEccBer`：多个副本按置信度投票后、Reed–Solomon 纠错前的错误率。

若 Raw BER 大于 0、Voted BER 为 0，说明副本投票消除了错误；若 Voted BER 大于 0 但最终成功，说明纠错层修复了错误。最终失败并不只由一个总 BER 决定，Header 和 Data 的位置、错误聚集方式及协议检测状态都重要。

## 5. Reed–Solomon 修复数

当前水印协议的 RS(255,223) 每个完整块含 32 个校验符号，理论上可修复最多 16 个未知位置的错误符号：

```text
t = (255 - 223) / 2 = 16
```

报告中的 RS 修复数为 0，不代表物理信道完全无错误；错误可能在进入 RS 之前已由副本投票去除。反过来，错误数相同但分布不同，也可能产生不同恢复结果。

## 6. 置信度

QIM 读取会比较某个系数到 bit 0 与 bit 1 两组量化格点的距离。两者差异越明显，置信度越高。平均置信度容易被少数高值掩盖，因此报告同时保留 P10（第 10 百分位）来观察较弱的一段读数。

置信度是算法内部判决强弱，不是“图片可信度”或“作者真实性概率”。

## 7. 质量指标的两个参考点

- `AttackOnlyQuality`：比较扰动前的水印基线与扰动后结果，尽量只描述攻击带来的变化。
- `EndToEndQuality`：比较原始载体与最终结果，同时包含水印写入和扰动的影响。

常用误差关系为：

```text
MSE  = 平均平方误差
PSNR = 10 log10(255² / MSE)
```

PSNR 越大通常表示像素误差越小，MSE 为 0 时 PSNR 为正无穷。SSIM-Y 观察亮度结构相似性。局部 16×16 网格统计 RGB/Y 误差，不是局部 SSIM Map。

几何操作可能改变尺寸。没有一一对应坐标时，全参考指标显示 `N/A/SizeMismatch`；用 0 代替会错误地表示“完美”或“最差”。

## 8. 扰动链与首次失败

设链为 `T1, T2, ..., Tk`，第 `i` 个前缀输出为：

```text
I_i = Ti(Ti-1(...T1(I_0)))
```

“首次失败”是最小的 `i`，使得从 `I_i` 恢复失败。它说明整个前缀组合到这里首次失败，不能证明 `Ti` 单独作用时必然失败。某些非线性处理可能让后续 `I_j` 偶然重新跨过判决边界，因此系统保留 `RecoveredAfterFailure`，不强迫结果单调。

## 9. 可复现随机性

实验噪声从主种子、案例身份、步骤身份等稳定派生子种子。目标是让案例执行顺序变化时，某个案例仍得到同一随机序列。简化表达为：

```text
subseed = Hash(master seed, profile, point, trial, step)
```

哈希负责稳定分离，SplitMix64-v1 生成实验伪随机序列。这是复现实验的工程随机源，不可替代水印协议中 salt、nonce 和 Mapping Key 所需的密码学随机源。

## 10. 如何写出不过度外推的结论

一个完整结论至少包含载体样本、Payload、Profile、扰动链顺序、扫描参数、trial、种子、实现与编码器版本。正确表述是“在这些条件下，从某参数点开始观察到失败”，而不是“该 Profile 能抵抗所有同类攻击”。
