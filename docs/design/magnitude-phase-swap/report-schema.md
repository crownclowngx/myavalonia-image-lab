# Magnitude/Phase Swap Report Schema 1

已实现协议名：`magnitude-phase-swap-report-v1`。JSON 保存完整结构化事实；CSV 保存稳定扁平摘要与结构化指标状态，二者都不包含路径或像素。

当前 schema 1 报告记录规范画布内容指纹、完整 Recipe、供体/共轭/虚部/Parseval、空间指标、raw/裁切统计、耗时、版本和限制说明。源原始尺寸与内容矩形仍只在当前 Session/UI 中使用，未写入 schema 1；若未来加入必须升级或向后兼容扩展，不能静默改变既有字段。

## 报告内容

- A/B 原尺寸、规范内容矩形、缩放方式、留白比例和规范画布内容指纹；
- canvas size、Recipe fingerprint、幅度模式/参数、相位模式/参数；
- 未定义相位频点数量、借用未定义相位的幅度能量比例；
- 相差 π 歧义数、自共轭频点过零数、共轭最大误差和 IFFT 虚部残差比；
- 对幅度供体的相对 L2 幅度误差；
- 对相位供体的幅度加权圆周误差；
- raw real min/max/mean、低端/高端裁切数与比例；
- 对规范 A/B 的 NCC 与梯度相关及结构化 N/A 原因；
- 适用时对规范 A/B 的 PSNR-Y、SSIM-Y；科学投影时固定为 N/A 和原因；
- 运行耗时、实现版本、FFT 协议和“不能推导普遍因果百分比”的固定限制说明。

## 禁止内容

报告不得包含绝对路径、原文件名、用户目录、原图或重建像素、复数频谱、缩略图、异常堆栈和任意外部标识。CSV 使用 invariant culture，空值与 N/A reason 分列，并对每个文本字段执行 RFC 风格双引号转义。
