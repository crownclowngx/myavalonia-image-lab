# Magnitude/Phase Swap 新手说明书

## 这个实验在看什么

把图片想成许多不同方向、大小和位置的波叠在一起：

- 幅度说明某种波有多强；
- 相位说明这些波在什么位置互相对齐。

交换两张图片的幅度和相位，经常会看到重建轮廓更像“相位来源”，明暗和纹理强弱又受到“幅度来源”影响。这里的“经常”不是永远，界面会把指标和例外一起展示。

## 第一次使用

1. 选择图片 A 和 B。
2. 保持默认 512，点击“准备双输入”。
3. 确认两张图片都完整放在白色方形画布内；这两张画布才是实际参加实验的输入。
4. 点击“A 幅度 + B 相位”。
5. 再点击“B 幅度 + A 相位”，比较两个结果的主体轮廓。
6. 打开“相位-only”，观察边缘和位置线索；它的灰色只是科学显示，不是原始亮度。
7. 拖动“相位 A→B”，观察结构怎样变化；再拖动“幅度 A→B”，观察能量和对比怎样变化。

## 页面区域

- 顶部：选择 A/B、画布大小、准备、取消和导出；
- 左侧：规范化后的 A/B，显示内容矩形和留白；
- 中间：A/B/结果的幅度谱或相位谱；
- 右侧：当前重建、实验模式和插值参数；
- 底部：频点详情、质量指标、警告、进度和结果是否过期。

## 常见提示

- “结果已过期”：输入、画布、模式或滑块已变化，需要重新计算；
- “相位未定义”：该频点幅度接近零，角度没有稳定含义，不是程序崩溃；
- “科学投影，不可比较 PSNR/SSIM”：相位-only 被放大到可见范围，不能和原亮度直接算这两项；
- “裁切较多”：逆变换值有不少低于 0 或高于 255，PNG 只能裁切；
- “虚部残差超限”：频谱没有保持实值图片所需的共轭关系，候选结果会被拒绝；
- “未独立证明更像”：指标只描述当前两张规范画布，不给出普遍因果结论。

## 怎样选图更容易观察

- 先选主体位置相近、轮廓差异大的两张图；
- 避免一张几乎全白、另一张几乎全黑；
- 图片四周大量留白会成为频谱的一部分；
- 若两张图主体位置完全不同，相位交换可能产生重叠或环绕，这也是可解释结果；
- 512 通常足够，1024 更清楚但占用更多内存和时间。

## 保存结果

PNG 只保存当前方形分析画布，不是原尺寸成品照片。Recipe 保存可复现实验参数，Report 保存脱敏数值事实；两者都不保存绝对路径或原图像素。当前功能已经接入插件与 Standalone；真实 Host 和发布包验收仍留到发布阶段。
