# Magnitude/Phase Swap 数学原理

## 1. 规范输入

两张图片必须先位于同一离散坐标系，才能逐频点交换分量。V1 把 A、B 分别按比例放入同一个 `N×N` 方形画布，`N∈{256,512,1024}`：

- 保持宽高比并居中，不拉伸；
- 缩小时使用确定性面积聚合，放大时使用像素中心双线性采样；
- RGBA 先在白色背景合成，再按 `Y=0.299R+0.587G+0.114B` 得到 `[0,255]` 亮度；
- 图片外的 letterbox 固定为白色 255；
- UI 必须显示规范化后的 A/B，因为后续结论只针对这两个画布，不直接针对原文件。

固定白底与现有 ImageLab 亮度质量语义一致，也避免透明 RGB 隐藏值进入 FFT。画布边界会改变频谱，因此内容矩形、缩放和留白比例必须进入报告。

## 2. 二维 FFT、幅度和相位

对规范画布 `f(x,y)` 执行现有未归一化前向、逆变换除以样本数的二维 FFT：

```text
F(u,v) = Σx Σy f(x,y) exp(-i2π(ux/N + vy/N))
F(u,v) = M(u,v) exp(iφ(u,v))
M       = hypot(Re(F), Im(F))
φ       = atan2(Im(F), Re(F))
```

工作数组保持未中心化坐标；`fftshift` 只服务显示。算法不得在中心化数组上交换后再忘记还原。

当 `M <= max(1e-12, maxMagnitude×1e-12)` 时，相位在数学上没有可靠含义。实现把显示值记为 0，同时统计“相位未定义频点”；如果另一个图在同一频点提供非零幅度，结果仍可生成，但必须把借用未定义相位的数量和能量比例展示出来。

## 3. 交换

```text
F(A幅度+B相位) = MA exp(iφB)
F(B幅度+A相位) = MB exp(iφA)
```

幅度控制各频点能量和整体对比度；相位编码不同频率分量在空间中的相对对齐。常见自然图像中，相位交换后的轮廓往往更接近相位供体，但这不是无条件定理。留白、周期边界、平移、零幅度频点、强 DC、裁切和输出量化都可能改变肉眼结论。

因此产品同时报告：

- 与幅度供体的相对幅度误差；
- 与相位供体的加权圆周相位误差；
- 与 A/B 的空间 NCC、梯度相关；
- 固定裁切投影下与 A/B 的 PSNR-Y、SSIM-Y；
- IFFT 虚部残差和字节裁切比例。

## 4. 只使用幅度或只使用相位

### 4.1 只使用幅度

```text
FmagOnly = M exp(i0)
```

这不是“没有空间信息”的严格证明。零相位把所有频率分量按同一相位对齐，IFFT 结果通常在周期原点附近集中并带有对称结构。V1 展示未经空间平移的真实结果，并用原点标记解释环绕；不为了“好看”偷偷把结果移动到中心。

### 4.2 只使用相位

```text
FphaseOnly = U exp(iφ)
U = 1，当原频点幅度高于零阈值；否则 U = 0
```

单位幅度结果的数值范围与输入亮度不在同一量纲。它使用固定的“零中心对称百分位”科学投影：取 `abs(raw)` 的 99.5 百分位为尺度，把 `[-scale,+scale]` 映射到 `[0,255]`，零映射为 127.5。该图只用于观察和诊断，PSNR/SSIM 显示 `N/A/DisplayProjectionNotComparable`；NCC 与梯度相关仍基于未投影 raw double。

## 5. 幅度插值

幅度从 A 到 B 的线性插值：

```text
M(t) = (1-t)MA + tMB,  t∈[0,1]
```

相位必须显式固定为 A 或 B。`t=0` 和 `t=1` 是精确端点；插值不能在 byte 图上进行，也不能先对数化幅度。线性幅度插值不等于线性能量插值，界面需明确使用“幅度比例”而不是“能量比例”。

## 6. 相位插值

相位是圆周量，不能直接用普通算术平均。对非自共轭代表频点使用最短圆弧：

```text
Δφ   = wrapToPi(φB - φA)
φ(t) = wrapToPi(φA + tΔφ)
```

幅度必须显式固定为 A 或 B。相差恰为 `π` 时最短方向不唯一，V1 以代表频点的虚部、实部和行优先索引执行确定性 tie-break，并把歧义计数写入诊断。

## 7. 共轭安全与自共轭频点

实值图片满足：

```text
F((-u) mod N, (-v) mod N) = conjugate(F(u,v))
```

实现只计算每个共轭对的规范代表，再把另一点写成精确共轭。DC 与 Nyquist 轴交点等自共轭频点必须保持纯实数；其相位只能是 0 或 π。相位插值在自共轭点不走复数圆弧，而对两个实数符号做确定性端点选择；恰好切换时允许系数为 0，并记录一次自共轭过零。不得以 IFFT 后“丢掉虚部”掩盖非共轭频谱。

## 8. 逆变换、投影与指标

混合、幅度插值和相位插值结果先 IFFT，检查：

```text
imaginaryResidualRatio = max(abs(imag)) / max(1, max(abs(real)))
```

门禁目标为 `<=1e-10`。普通结果按 ToEven 舍入并裁切到 `[0,255]`；裁切数与比例必须显示。单分量科学投影不冒充原亮度结果。

频域供体误差使用未投影复数频谱。空间 NCC 使用去均值 raw double；常量输入返回结构化 `UndefinedZeroVariance`。梯度相关使用固定中心差分或既有、已冻结的梯度实现，边界语义必须在 G1 测试前唯一确定。PSNR-Y/SSIM-Y只在固定亮度裁切投影可比较时计算。

这些指标是观察事实，不输出“相位贡献 80%”或“结构一定由相位决定”之类未经定义的因果百分比。
