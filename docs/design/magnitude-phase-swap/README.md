# Magnitude/Phase Swap／幅度与相位交换

本能力把两张图片投影到同一灰度分析画布，交换或插值二维 FFT 的幅度与相位，并把源频谱、合成频谱、空间重建和质量事实放在同一条可追溯链路中。它用于回答“图像结构更受幅度还是相位影响”，不是照片融合器、自动配准器或原尺寸编辑器。

## V1 固定范围

- A 幅度 + B 相位、B 幅度 + A 相位；
- A/B 的只使用幅度和只使用相位重建；
- 幅度线性插值与相位最短圆弧插值；
- A、B、当前结果的幅度谱、相位谱、空间重建和频点探针联动；
- 幅度/相位供体误差、虚部残差、裁切、NCC、梯度相关，以及适用时的 PSNR-Y/SSIM-Y；
- 256、512、1024 三档分析画布、取消、generation、轻量快照和脱敏报告；
- 当前结果的 PNG、Recipe JSON 和 Report JSON/CSV 导出。

V1 固定为白底 Alpha 合成后的灰度亮度实验。彩色逐通道交换、自动配准、原尺寸输出、视频、批处理和任意频谱编辑不在本阶段。

## 首要设计规定

SOLID 是首要约束。公共 FFT 继续只负责变换；产品专用 Domain 负责分量选择、插值和诊断；Application 负责双输入 Session、取消与提交；Document/View 只负责状态和显示。只在文件、时钟和应用用例等真实替换边界使用接口，不为固定公式建立 Strategy/Factory，也不建立万能“频域实验引擎”。

所有新增生产代码注释使用中文。复杂公式、共轭配对、自共轭频点、缓冲所有权、取消位置和结果提交条件必须有详细设计说明；简单属性和显而易见赋值不堆砌注释。

本阶段不使用 AIFLOW，不增加 Windows CI，也不执行真实 Host、ZIP、签名、安装或发布门禁。
