# Magnitude/Phase Swap 使用指南

## 最短实验闭环

1. 选择结构差异明显的 A、B；建议先用主体居中、留白较少的图片。
2. 选择 512 画布并点击“准备双输入”。先检查规范化后的 A/B 内容矩形和留白。
3. 运行“A 幅度 + B 相位”，观察结果轮廓更接近谁。
4. 切到“B 幅度 + A 相位”，用同一频谱量程和同一缩放位置比较。
5. 分别查看 A/B 的幅度-only 与相位-only；注意相位-only 是零中心科学投影。
6. 固定 B 相位，把幅度从 A 插值到 B；再固定 A 幅度，把相位从 A 插值到 B。
7. 查看供体误差、NCC、梯度相关、PSNR/SSIM、虚部残差和裁切比例。
8. 满意后导出当前 PNG、Recipe 和脱敏报告。PNG 只代表规范分析画布。

## 输入与画布

- 256 适合快速或教学测试，512 是默认，1024 用于细节复核；
- 两张原图允许尺寸和宽高比不同，但都按比例居中进入同一方形白底画布；
- 规范化可能引入缩放和边界频率，UI 必须先显示规范输入，用户才能解释结果；
- 更换图片或画布会清空两张频谱和全部结果；
- 快照不保存绝对路径，恢复后必须重新选择图片并重新准备。

## 实验模式

| 模式 | 幅度 | 相位 | 主要观察 |
| --- | --- | --- | --- |
| A 幅度 + B 相位 | A | B | B 的空间组织是否更突出 |
| B 幅度 + A 相位 | B | A | A 的空间组织是否更突出 |
| A/B 幅度-only | A/B | 0 | 能量在同相位对齐后的对称/原点结构 |
| A/B 相位-only | unit/zero-aware | A/B | 去掉原幅度权重后的边缘与位置线索 |
| 幅度插值 | A→B | 固定 A 或 B | 能量分布连续变化 |
| 相位插值 | 固定 A 或 B | A→B 最短圆弧 | 空间组织连续变化与局部跳变 |

相位滑块的中间值不等于两张图片的 Alpha 混合。自共轭频点和相差 π 的频点存在确定性过零/tie-break，诊断区会显示计数。

## 频谱联动

- A、B 和结果的幅度谱使用同一个对数尺度与共同最大幅度上限；
- 相位固定映射 `[-π,+π]`，零幅度区使用无数据纹理，不伪造相位颜色；
- 鼠标在任一频谱悬停时，三张频谱定位到同一个未中心化频点，并显示中心化坐标、cycles/pixel、幅度、相位和是否自共轭；
- 空间图同步 pan/zoom，但频谱与空间图不共享像素坐标；
- 当前结果 fingerprint 必须同时绑定图片指纹、画布、模式、参数和 generation，任何一项变化都使导出资格失效。

## 指标判断

- 幅度供体相对误差接近 0，证明结果使用了指定幅度，不证明视觉更像该图片；
- 相位供体加权误差接近 0，证明可定义频点使用了指定相位；
- NCC 与梯度相关更适合观察结构接近；常量或零方差时显示 N/A；
- PSNR/SSIM 受亮度、裁切和输出投影影响，只与规范 A/B 比较；
- 相位-only 的 PSNR/SSIM 必须是 N/A，因为科学投影不保留原亮度量纲；
- 虚部残差超门限表示共轭构造失败，结果不得提交；
- 高裁切比例表示频谱交换产生了大量超出显示亮度的值，应保留警告而不是自动拉伸掩盖。

## 导出与隐私

PNG 使用当前结果的实际投影，尺寸固定为选定画布。Recipe/Report 保存内容指纹、规范化矩形、算法版本、参数和指标，不保存绝对路径、原图、频谱数组或用户目录。导出不能覆盖 A/B；编码后需要内存回读、原子发布和真实目标回读。

## 限制

V1 不做自动配准、彩色逐通道交换、原尺寸重建或“相位决定结构”的统计学证明。同一主体发生平移时幅度可能几乎不变而相位改变，这正是实验价值的一部分；但 letterbox、裁切和缩放也会成为相位与幅度的一部分，必须结合规范输入解释。
