# LSB 隐写与统计实验：新手说明

## 它做什么

一张 8 位图片的 R、G、B 每个字节都有 8 个 bit。bit 0 权重为 1，bit 1 权重为 2。本实验把一个很小的 `ILSB` Frame 写入这些低位，因此肉眼变化通常很小，但这不意味着不可检测，也不意味着数据能经受 JPEG、缩放或滤波。

## 最短流程

1. 选择 PNG 或 JPEG 载体，点击“准备载体”。只有 Alpha=255 的完全不透明像素计入容量。
2. 输入 UTF-8 文本，或选择不超过 65,536 字节的二进制文件。
3. 选择 R/G/B/RGB、bit 0/1、顺序/伪随机位置和 seed。
4. 查看容量。固定 Header 占 20 字节；容量不足时不会自动截断或换参数。
5. 点击“写入并双重自检”。工具会从内存结果回读一次，再把结果编码成 PNG、真实解码并回读一次。
6. 查看 Cover/Stego、位置与实际变化、bit 前后代理，以及精确数值。
7. 可选运行一个 JPEG、缩放往返、高斯或中值预设，观察 BER、Frame 状态和 PSNR。
8. 只有自检通过后才能原子导出 PNG、JSON 或 CSV。

## 参数怎么选

- `R/G/B`：每个不透明像素一个槽；`RGB` 固定按 R→G→B 产生三个槽。
- `bit 0`：单字节最多变化 1；`bit 1`：最多变化 2。
- `顺序`：从左上行优先写，适合观察局部集中变化。
- `伪随机`：seed 决定无重复位置，相同 seed 可复现。它不是密码，别人知道 seed 就能复现位置。
- `Scope`：全图可用槽、本次选择槽，或仅顺序策略的连续前缀。Cover 与 Stego 永远使用同一 Scope。

## 如何读结果

- `CRC 通过`：只表示当前字节没有被 CRC 发现意外损坏，不证明来源可信。
- `one ratio/entropy`：描述目标 bit 的 0/1 分布；接近 50% 不是隐写证据或安全证据。
- `χ²/p`：描述 PoV 模型下的观测；p 不是图片含隐写的概率。
- `transition`：相邻目标 bit 从 0→1 或 1→0 的比例；无有效邻接显示 N/A。
- `BER`：原 Frame 与扰动后可读 bit 的错误比例；缺失 bit 不按 0 处理。

快照只保存路径和轻量参数，不保存 Payload、Frame、像素或结果。恢复后必须重新提供 Payload 并显式运行。
