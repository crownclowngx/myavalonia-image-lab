# 内容感知缩放数学原理

## 可见亮度与 Sobel

RGBA 是非预乘字节。先把颜色合成固定白底，排除全透明像素隐藏 RGB 对路径的影响：

```text
Cvisible = (A/255) C + (1-A/255) 255
Y = 0.299 Rvisible + 0.587 Gvisible + 0.114 Bvisible
```

然后使用标准 3×3 Sobel。边界钳制到最近像素；能量按 `4×255×sqrt(2)` 归一化并钳制到 `[0,1]`。
区域有效能量为 `Ebase + 1000 I(protect) - 1000 I(preferRemoval)`。偏置有限，保证必要时仍有合法路径。

## 最小能量缝

垂直缝每行有一个 x，且相邻行 `|Δx|≤1`：

```text
M(0,x)=E(0,x)
M(y,x)=E(y,x)+min(M(y-1,x-1), M(y-1,x), M(y-1,x+1))
```

水平缝把列作为主轴、y 作为次轴，使用同一坐标映射而不转置图片。每个单元保存累计 `double` 和 `sbyte`
前驱偏移。代价相等时选择较小次轴坐标，终点相等也选择较小坐标，因此结果确定且可用穷举小矩阵验证。

## 删除与插入

删除垂直缝使每行去掉对应 x，删除水平缝使每列去掉对应 y；同一路径同步搬移 RGBA 和三态蒙版。
每次删除后重新计算完整能量，V1 不做局部增量优化。

放大先在影子副本重复“找缝→删除”，并维护“当前位置→批次起点坐标”映射，避免反复选择新插入的低能量像素。
真实图逐条插入时，按已插入的原坐标修正每行/列偏移。新像素位于缝右侧或下方。

颜色插值先计算 Alpha 和预乘 sRGB 的平均，再反预乘；两端全透明固定输出 `(0,0,0,0)`。蒙版传播优先级为
Protect > PreferRemoval > Normal，最终字节使用 `MidpointRounding.ToEven`。

## 普通缩放参考

双线性和 Catmull–Rom 双三次都使用像素中心逆向映射与 clamp 边界，并在预乘 Alpha 空间采样。双三次的
Catmull–Rom 参数为 `a=-0.5`；负权重可能过冲，因此 Alpha 钳制到 `[0,1]`，预乘颜色钳制到 `[0,Alpha]`。

两种结果尺寸一致后可以计算 MAE、RMSE、PSNR-Y/RGB、全局 SSIM-Y 和 Alpha 误差。这些量只描述结果之间
有多不同，因为没有 ground truth，不能推导审美优劣。
