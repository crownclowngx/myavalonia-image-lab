# 内容感知缩放新手说明书

## 最短流程

1. 点击“选择…”并“载入”。载入只解码和检查 200 万工作像素预算，不自动运行算法。
2. 设置目标宽、高。单轴变化最多为输入轴的 25%，一次最多 256 条缝。
3. 可选画笔：保护区用洋红斜纹，优先删除用黄绿反向斜纹，擦除恢复普通状态。后画覆盖先画。
4. 选择“自动／宽优先／高优先”和“双线性／Catmull–Rom 双三次”，点击“建立计划”。
5. 点击“预览下一缝”。红色实线表示将删除，青色虚线表示将插入；此时图片尚未改变。
6. 点击“单步”只应用一条缝，或“播放”持续执行。暂停阻止下一步开始，取消终止当前计算。
7. 完成后点击“生成普通缩放对照”，查看并排结果、差异图和 `seamVsReference` 指标。
8. 按需导出 PNG、JSON 或 CSV。PNG 不能覆盖源文件；未完成或已过期结果不能导出。

## 能量和区域怎样读

“基础能量”来自白底可见亮度的 Sobel 梯度；“偏置后能量”再加保护 `+1000` 或优先删除 `-1000`。
线性/对数选项只改变灰度显示，不改变算法路径。步骤文本同时列出基础累计能量、有效累计能量和两类区域命中数。

## 状态与常见提示

- 修改目标、轴顺序、参考算法或笔划后，旧计划和结果立即过期，需重新建立计划。
- 重置会回到输入图并重放当前笔划，不保存或恢复所有历史帧。
- “实际值 / 上限 / 建议”提示表示任务在分配 Sobel/DP 等大数组前被预算门禁拒绝。
- 1 像素宽/高的图片缺少插入邻居；请先用普通缩放把相应轴扩到至少 2 像素。
- 恢复 Document 后只恢复路径文本、参数和笔划意图；必须由用户再次显式载入图片。

## 不要怎样解释结果

保护不等于绝对不可删除，优先删除不等于完整对象移除，Seam Carving 也不理解人物、文字或物体。
普通缩放与 Seam 结果没有无失真 ground truth，因此 PSNR/SSIM 不能说明哪一张“更美”或“更正确”。
