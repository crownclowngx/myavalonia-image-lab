# 周期噪声与陷波器使用与设计指南

## 产品闭环

1. 显式选择 PNG/JPEG、分析通道和 512/1024/2048 最大边档位，建立每 Document 独占 Session。
2. 运行候选检测，或直接在中心化原始/处理后频谱上单击频点。
3. 复核候选分数、突出度、周期提示、共轭位置和风险事实。
4. 生成保守建议草案，或加入/移除整对手动中心；调整半径、强度、过渡和阶数。
5. 预览原/结果频谱、原/结果图、符号/绝对差异、能量损失、PSNR/SSIM 和 raw 越界。
6. 显式“采用草案”。采用会使旧结果过期，必须重新执行代理或预算内原尺寸结果。
7. 只有已采用、非草案、Session/Recipe 指纹一致的结果可导出；源文件不会被覆盖。

## 参数与上限

- 通道：R、G、B、Y、Cb、Cr；切换通道释放旧 Session。
- 分析档位：512、1024、2048 最大边；FFT 补零总预算沿用共享 2048² 上限。
- 默认检测：DC 排除 0.025 cycles/pixel、稳健分数 6、突出度 0.2、NMS 距离 0.0125。
- 候选最多 64 对、自动建议最多 12 对、配方最多 32 对中心。
- 半径：`(0,0.25]` cycles/pixel；强度 `[0,1]`；Butterworth 阶数 1–12。
- Ideal、Butterworth、Gaussian 是一个完整 switch，不建立无真实替换需求的 Strategy/Factory 层次。

## 草案与采用状态

`DraftRecipe` 和 `AcceptedRecipe` 相互独立。检测不会改变任何配方；自动建议、手动点选和参数调整只创建或修改草案。
修改草案会让草案结果过期，但不会偷偷替换已采用配方。采用草案后旧代理结果也不会被复用，因为它仍带 `IsDraft=true`；
重新执行得到 `IsDraft=false` 且指纹一致的结果后，导出命令才启用。

快照只保存源路径、通道、档位、检测设置和两份有限配方。恢复不会读文件、检测、FFT、IFFT，也不保存图片、Bitmap、
候选数组或频谱。路径、通道和档位变化释放 Session；检测设置只使候选过期；Notch 参数只使草案结果过期。

## SOLID 设计思路

- SRP：`PeriodicPeakDetector` 只检测，`RadialSpectrumBaseline` 只估计背景，`NotchMaskFactory` 只光栅化，
  `PeriodicNoiseLossAnalyzer` 只报告数值事实，Document 不包含算法循环或 JSON。
- OCP：诊断、导出、检测和遮罩分别位于窄类型；增加一种报告项不要求修改峰检测或 IFFT。
- LSP：所有用例在取消、释放、异常和指纹不一致时拒绝提交半成品。
- ISP：准备、检测、坐标映射、预览、原尺寸、配方导入/导出、候选摘要和图片导出各有窄接口。
- DIP：Application 依赖图片编解码、有界文本读取和原子写入端口；Feature 不创建 Infrastructure。

数值服务注册为 singleton；Document、Session、候选、草案、结果、Bitmap 和取消源归每个 Document Scope 所有。
设计模式只使用不可变值对象、构造注入、窄用例和显式状态转换，没有 Mediator、Event Bus、反射发现或通用流水线。

## 误判与损失边界

织物、网格、建筑立面、文字栅格等真实纹理也可能产生离散峰。风险只报告 NearDc、NearNyquist、宽峰/脊线、密集邻域、
低突出度、自共轭等可复现事实，不输出设备来源概率或“修复成功”分数。导出图片无法从自身恢复已抑制的真实频率；
能量移除率、修改 bin 比例、最大差异、PSNR 和 SSIM 必须与差异图一起判断。
