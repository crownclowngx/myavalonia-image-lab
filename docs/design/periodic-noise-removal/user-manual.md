# 周期噪声与陷波器新手说明书

## 它适合做什么

图片中稳定重复的横纹、竖纹或斜纹，常在频谱中形成成对亮点。本工具让你观察这些“候选频率峰”，再用成对陷波做实验。
它不会断言亮点一定是噪声；规则纹理也可能产生相同现象。

## 最短操作

1. 选择图片，通道先用 `Y`，档位先用 `1024`，单击“载入并缓存 FFT”。
2. 单击“运行候选检测”。候选列表给出频率、约略周期、分数和风险原因。
3. 单击“生成保守建议草案”，或在原始频谱上单击一个亮点。程序会自动同时选择它的共轭点。
4. 先用 Gaussian、半径 0.01、强度 0.9，单击“立即预览/重建”。
5. 同时观察处理后频谱、结果图、红蓝符号差异、绝对差异和损失摘要。
6. 若真实纹理损失可接受，单击“采用草案”，再单击“立即预览/重建”。
7. 此时才可导出结果或遮罩 PNG；如原图在预算内，也可先执行原尺寸结果。

## 三种过渡的直觉

- Ideal：半径内突然抑制，边缘最硬，可能更容易产生振铃。
- Butterworth：由阶数控制过渡，阶数越高越接近硬边界。
- Gaussian：最平滑，通常适合作为第一次观察的默认值。

强度 0 是全通，1 表示陷波中心完全抑制。半径越大，可能损失的附近真实纹理越多。多个陷波重叠时取最小增益，
不会因为中心数量增加而暗中相乘加重抑制。

## 常见疑问

“没有候选”不等于“没有噪声”，只表示当前通道、档位和冻结阈值下没有通过规则的峰。
“高风险”也不等于禁止，它提醒你重点观察差异。草案预览不能导出；采用之后结果仍会过期，这是防止把未确认预览误当正式结果。
工具永远要求新输出路径，不会覆盖源图片。
