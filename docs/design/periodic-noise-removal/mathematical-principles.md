# 周期噪声与陷波器数学原理

## 坐标与共轭

FFT 内部保存自然索引，显示和配方使用中心化频率：`fx=kx/W`、`fy=ky/H`，范围为 `[-0.5,0.5)`。
实值图片满足 `F(-f)=conj(F(f))`。因此每个陷波中心必须与共轭中心成对，自共轭 DC/Nyquist 点只出现一次。
配方保存 cycles/pixel，不保存画布像素；映射到另一尺寸时使用固定的 AwayFromZero 舍入并重新成对。

## 候选检测

每个频点先计算对数功率：

```text
L(u,v) = log(1 + |F(u,v)|²)
```

径向背景用 128 个半径桶和每桶 256 格固定直方图估计中位数与 MAD：

```text
score = (L - medianRadius) / max(1.4826 × MADRadius, 1E-6)
```

只有 3×3 邻域的严格局部最大值、分数与突出度同时达标才进入临时候选。平台按自然线性索引稳定决胜；共轭归并后按
分数、突出度和 canonical 索引排序，再按环面距离执行 NMS，最多保留 64 对。取消时抛出，不返回部分候选。

## 单中心 Notch

令 `d` 为环面频率距离，`r` 为半径，`a` 为振幅衰减强度：

```text
Ideal:       A(d)=a, d<=r；否则 0
Butterworth: A(d)=a/(1+(d/r)^(2n))
Gaussian:    A(d)=a×exp(-ln(2)×(d/r)²)
H(d)=1-A(d)
```

Butterworth/Gaussian 在 `d=r` 时衰减为中心的一半。这里的 `H` 是复频谱振幅增益，不是功率或 dB。
多个中心采用 `Htotal=min(H1,H2,...)`，使重叠区不会隐藏地乘法叠加。遮罩最终必须有限、位于 `[0,1]`，并通过
共享 `FrequencyGainMask` 的 1E-12 共轭对称门禁。

## 重建与损失

处理后频谱是精确的 `F×H`。共享 `FrequencyMaskApplier` 对副本执行 IFFT，最大虚部残差超过 `1E-8` 即失败。
频谱能量移除率按 `|F|²` 与 `H²` 计算。空间域同时报告 raw 越界、颜色裁切、通道 MAE/最大差异、PSNR 和全局 SSIM-Y。
这些都是数值事实，不足以单独证明视觉质量提升。
