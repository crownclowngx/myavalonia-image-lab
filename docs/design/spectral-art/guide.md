# Spectral Art 开发与高级使用指南

## 固定协议

- 载体只使用 Y 通道，全局 FFT 补零后不得超过 2048×2048。
- Pattern 最大 512×512；强度默认 2.0、范围 `[0,8]`；径向稳健尺度下限 0.15。
- 主区域使用中心化归一化频率 `[-0.5,0.5]` 和闭开边界，离散使用 `MidpointRounding.ToEven`。
- 主区域至少 8×8、占频谱不超过 20%，必须位于规范半平面并避开 DC、坐标轴、Nyquist 与自共轭点。
- IFFT 最大虚部必须不超过 `1E-8`；参数自动渲染防抖 200 ms。

## Pattern

文字经 `ISpectralTextRasterizer` 适配 Avalonia 字体，领域只接收 RGBA。Logo 和二维码只读取已有图片。Alpha 先按黑/白背景合成，再计算暗度；二值模式用专用最近邻以保持硬边，灰度模式复用目标尺寸面积缩放。Pattern 构造时复制权重并生成不包含路径和原文字的 SHA-256 截断指纹。

## 生命周期与资源

准备载体时只解码一次并创建只读源图、Y 平面、频谱和原频谱预览。渲染时创建唯一 `Complex[]` 工作副本；全部频域诊断完成后，该数组交给 IFFT 原地消费。Document 以 generation、取消源和串行闸门拒绝迟到提交，异常或取消不替换 Session、Pattern 或最后有效结果。关闭时先阻止新提交，再取消并释放 Bitmap 与 Session。

## UI 与失败语义

区域控件使用 Uniform/letterbox 坐标，可拖动矩形或四角手柄，方向键移动，Shift 加速。绿色是主区域，青色是共轭副本，橙红是解释性禁止区；真正合法性仍由 Domain 判定。任何超预算、非法区域、非有限值、配方歧义、过期结果或 PNG 回读失败都会拒绝，不会静默裁切、缩小、覆盖源文件或发布半成品。

## SOLID 设计思路

数值对象和服务保持单一职责；Application 只协调窄用例；平台字体、文件窗口、编解码和磁盘写入由端口隔离；Document 不接触 FFT、复数、像素循环、共轭公式或 JSON DTO。没有建立抽象工厂、事件总线、算法注册中心或跨 Feature 继承层次。
