# Spectral Art 新手说明书

1. 选择 PNG/JPEG 载体，点击“准备载体”。
2. 选择 Pattern 来源：文字、Logo 图片或二维码图片。二维码必须是已有图片，本功能不会生成或解析其内容。
3. 文字可设置字体、字号、字重和留白；图片可选择二值最近邻或灰度面积采样。
4. 点击“创建 Pattern”。
5. 在频谱画布拖动绿色矩形或四角手柄；也可聚焦画布后用方向键移动。
6. 设置强度。0 表示原图不变，默认 2.0，最大 8.0。参数稳定 200 ms 后会自动重算，也可点击“渲染”。
7. 比较载体、结果、4 倍空间差异、原/结果频谱和真实频谱差异。
8. 需要保存时导出 PNG、recipe 或 JSON/CSV 报告。

“可见性增加”只表示本次频谱前景与局部背景的相对差异，不代表机器识别率、二维码扫码成功率、隐写安全或抗压缩能力。绿色区域触碰中心、轴、边缘或面积过大时，领域门禁会解释并拒绝渲染。
