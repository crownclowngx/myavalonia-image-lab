# Wavelet Lab 新手使用说明

## 一次最短实验

1. 在“小波实验室”输入或选择 PNG/JPEG，点击“载入/建立代理”。
2. 保持默认 `Haar + Luma + 2 层`，点击“分析代理”。
3. 在中间选择层和 LL/LH/HL/HH；`LH` 是 X 低通/Y 高通，`HL` 是 X 高通/Y 低通。
4. 观察 `sigma` 与 Universal 建议；它只是建议，实际阈值仍由数值框决定。
5. 选择 Hard/Soft 和目标 LH/HL/HH，再次分析代理，比较重建与非零系数比例。
6. 点击“运行有限阈值×层数扫描”。没有干净参考图时，结果不会标出“最佳质量”。
7. 需要导出时点击“显式完整尺寸”，完成后再导出 PNG；代理结果不能导出为最终图。

## 干净参考图

参考图必须与源图宽高相同。它应代表你希望逼近的干净图，而不是另一张随意图片。只有完整尺寸结果才会计算
代理扫描会使用同样缩放规则生成的参考代理计算 PSNR/SSIM；最终结论仍应在完整尺寸结果上复核。数值更高表示更接近这张参考图，不等于所有人主观上都更喜欢。

## DCT/DWT 水印比较

输入有限文本 Payload，点击比较。程序会先检查两个载体都能容纳同一 Payload，再分别写入并用共同的 JPEG、缩放、
噪声、模糊、亮度和对比度案例读取。两种强度的单位不同；通过数量只描述当前图片与参数，不是普遍排名。

## 常见状态

- “结果已过期”：参数在完整计算后发生变化，请重新执行完整尺寸。
- “容量不足”：缩短 Payload 或换更大的不透明图片；程序不会截断后继续比较。
- “扫描已取消”：已完成案例保留，但不把部分曲线当成完整扫描。
- “最细 HH 样本少于 4”：图片/层级过小，MAD 建议不可用，可手动使用有限阈值。
- “参考图尺寸不一致”：选择与源图完全相同宽高的参考图。

## 解释限制

小波系数响应不是物体识别；平滑不等于真实细节恢复；PSNR/SSIM 不是审美评分；一次水印曲线不能证明一种变换
天生更鲁棒。请把本工具作为可复现实验台，而不是自动结论生成器。
