# 频域滤波新手说明书

1. 点击“选择 PNG/JPEG”，再点“载入并缓存 FFT”。状态栏会分别显示原图、分析代理和 FFT 补零尺寸。
2. 先选 Gaussian 低通、截止 0.2 和 Direct。观察幅度谱、灰度遮罩、IFFT 结果及红/蓝有符号差异叠层。
3. 降低截止会留下更少高频，通常让边缘扩散；面板中的梯度能量、PSNR 和 SSIM 只表示相对源图变化，不表示“质量提升”。
4. 切到 Ideal，比较边缘附近的过冲和振荡。raw 小于 0 或大于 255 是可测越界；是否称为 Ringing 还要结合理想截断和剖面解释。
5. 切到高通并选择 Centered。128 只是把正负高频搬到可见范围，不是“真实亮度”。
6. 选择 Additive 并从增益 1 缓慢增加。它把高频加回源信号，可能增加边缘梯度，也可能产生裁切，不能直接等同于更清晰。
7. 带通/带阻会出现内外两个截止。内截止必须小于外截止；平滑带通的峰值不一定为 1，真实曲线比矩形示意更可信。
8. 选择 7/15/31 核并执行空间比较。结果固定显示 Wrap、padded、raw double 和“有限核近似”，不要把更小误差解读为完全等价。
9. 原图在 2048² 预算内时可显式生成完整尺寸结果；否则仍可导出带尺寸标识的代理 PNG。参数变化后旧结果会禁止导出。

Ideal 没有有限过渡带；Butterworth 阶数越高通常越陡；Gaussian 最平滑。H=0.5 是频谱振幅的一半，不是功率电路术语中的 -3 dB。
