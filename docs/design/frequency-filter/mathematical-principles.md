# 频域滤波数学原理

## 坐标与传递函数

实现统一复用 `FrequencyCoordinates`。FFT 数组保持自然顺序，界面遮罩和幅度谱使用中心化显示；归一化径向半径把 DC 设为 0、Nyquist 方形角点设为 1。

低通原型为：Ideal 在 `r <= c` 时取 1，否则取 0；Butterworth 为 `1/(1+(r/c)^(2n))`；Gaussian 为 `exp(-ln(2)*(r/c)^2)`。后两者在 `r=c` 时振幅增益为 0.5。这里是振幅，不是功率 -3 dB。

高通是 `1-L`；带通是 `(1-L(r,a))*L(r,b)`；带阻是带通的逐点补集。这样低/高通以及带通/带阻严格互补。Butterworth 在对数域计算高次幂，避免溢出；Gaussian 下溢到 0 是合法阻带。

## 过渡带

过渡带只从规范截止和阶数派生，不重复持久化。它定义为低通原型从 90% 到 10% 振幅增益的半径区间：

- Butterworth：`r(H)=c*((1/H)-1)^(1/(2n))`；
- Gaussian：`r(H)=c*sqrt(-ln(H)/ln(2))`；
- Ideal：宽度为 0。

## IFFT 与输出语义

遮罩是实数、径向、中心对称，因此保持实值输入频谱的共轭对称。执行器先复制 Session 频谱，再逐点乘增益并 IFFT；缓存频谱永不原地修改。最大虚部超过 `1e-8` 会失败，不会静默丢弃。

- Direct：直接量化 raw 滤波信号。
- Centered：`128 + gain*raw`，用于观察零均值高通/带通信号。
- Additive：`source + gain*raw`，把高频分量加回一次。

Alpha 始终取自源图。Cb/Cr 补零使用 128 中性值，颜色回写继续使用既有六通道转换。

## 冲激响应与空间近似

遮罩 IFFT 得到周期冲激响应，空间原点位于 `(0,0)`。实现用循环索引完成 fftshift 语义，从中心截取 7、15 或 31 的奇数核。低通/带阻把截断核和修正为 1；高通/带通修正为 0，差值只加到中心，绝不对零和核做除法。

空间路径在同一 padded 网格上使用 Wrap 边界和 raw double。有限核舍弃了完整周期响应，所以比较结果是近似；耗时只覆盖数学核心，预热后测量三次并取中位数。
