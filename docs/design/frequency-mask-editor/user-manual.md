# 频谱遮罩编辑器新手说明书

频谱可以把图片理解为许多不同方向和密度的波叠加而成。画布中心附近通常对应变化缓慢的成分，越靠外通常对应更快的变化。
本工具让你手工降低某些频率的幅值，再观察图片如何变化；它不会自动判断哪些变化“更好”。

## 第一次实验

1. 选择一张较小的 PNG/JPEG。
2. 保持通道 `Y`、档位 `1024`，载入 FFT。
3. 选择“衰减画笔”，目标增益设为 `0`，opacity 设为 `1`。
4. 在频谱边缘画一小段，观察重建图和差异叠层。
5. 用“恢复橡皮”擦过同一区域，或使用撤销。
6. 把全局强度从 `1` 调到 `0`：`0` 表示暂时不应用编辑，历史不会消失。

黄色十字是当前探针，青色十字是它的共轭配对点。工具总会同时、安全地处理这两个点；此约束不能关闭。

## 如何理解诊断

- `M` 是编辑遮罩，`H` 是应用全局强度后的有效遮罩。
- 能量保留只表示当前幅值遮罩后的频谱能量比例，不等于信息量或质量。
- IFFT 虚部应低于 `1E-8`；超限会阻断结果。
- raw 越界和颜色裁切说明重建信号超出字节/颜色范围。
- PSNR/SSIM 越高通常表示越接近源图，不表示视觉上一定更好。

## 保存

- 重建 PNG：当前有效遮罩得到的图片。
- 遮罩显示 PNG：便于观察的灰度图，不能无损恢复 double 增益。
- 配方 JSON：保存归一化操作、强度、预算提示和指纹，可再次导入重放。

恢复工作区或导入配方后仍需显式选择/载入图片。配方可在不同 FFT 尺寸重放，但归一化位置相同不代表离散 bin 完全相同。
