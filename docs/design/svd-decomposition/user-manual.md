# SVD Decomposition 新手使用说明

## 最短实验

1. 选择一张 PNG/JPEG，保持代理最大边 128，点击“建立代理”。页面会同时显示原图尺寸和代理尺寸。
2. 保持“单通道 + Y”，点击“开始分解”。分解在后台进行，可随时取消。
3. 调整共同 Rank `k`。`k=0` 是合法基线；k 越大，参与重建的秩一分量越多，但不保证主观观感单调变好。
4. 选择分量索引。分量图中蓝色表示负值、灰色表示零、橙色表示正值；它是独立归一化观察图，不是普通像素图。
5. 选择 RGB 独立或 YCbCr 独立并重新分解。已完成策略会保留在当前 Document 的有限缓存中。
6. 点击“三策略比较”，程序按 Y、RGB、YCbCr 固定顺序串行运行，并保持三行原顺序，不自动宣布最佳策略。
7. 可导出当前 Rank 的分析代理 PNG，或导出 JSON/CSV 实验报告。

## 如何读结果

- “保留能量”是 Frobenius 范数意义下的矩阵能量比例，不是文件大小、码率或视觉满意度。
- “理论残差”来自被丢弃奇异值的平方和；“直接残差”来自实际 Rank-k 矩阵相减；二者一致用于检查数值实现。
- MAE/RMSE/PSNR/SSIM 在 8 位颜色转换和裁切后计算，只比较当前代理源图与代理重建图。
- 数值秩是诊断，不限制你观察尾部奇异值；接近数值地板的分量方向可能不稳定。
- 重复奇异值对应的子空间是稳定事实，但其中单个向量和单分量图没有唯一身份。

## 颜色策略

- 单通道：只替换所选通道，其他颜色来自代理源图。
- RGB 独立：R/G/B 各自分解，以共同 k 一次性组合。
- YCbCr 独立：Y/Cb/Cr 各自分解；Cb/Cr 以 128 为中性中心，重建时只加回一次。
- Alpha 不进入 SVD，所有重建图逐像素保留代理源图 Alpha。

## 常见状态

- “结果已过期”：源图、代理档位、策略、通道或 k 已变化，请重新完成相应步骤。
- “未收敛”：数值核心达到冻结的最大 sweep；该结果不会进入成功缓存或导出。
- “只能导出 PNG”：代理图片不提供 JPEG；报告另用 JSON/CSV。
- “禁止覆盖源图片”：另选输出路径，程序不会把代理结果写回源文件。
- “比较已取消”：只保留取消前完成的有序案例，不能当作完整三策略结论。

本工具不生成自定义压缩格式，也不计算文件压缩率。若需要评价保存体积，必须另行选择编码格式、质量参数和真实文件做实验。
