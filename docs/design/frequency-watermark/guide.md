# 频域隐式水印使用说明

第一次接触隐式水印时，建议先阅读 [新手使用说明书](user-manual.md)；公式与纠错背景见 [数学原理](mathematical-principles.md)。

## 水印写入

打开“水印写入”Document，选择 PNG/JPEG 源图片，输入文本或 JSON，也可以选择任意 Payload 文件。先执行“估算容量”，再选择隐蔽、均衡或鲁棒配置。容量不足时工具不会修改源图，也不会自动截断 Payload。

可选启用密码保护。密码不会进入 Document 快照，恢复作业后必须重新输入。默认输出 PNG；JPEG 会引入额外损伤，正式使用优先选择 PNG。点击“写入并自检”后，工具会对实际编码后的输出字节调用正式提取器；只有 Payload 完整恢复并通过完整性检查，结果才可以保存。保存使用同目录临时文件后原子替换，源图片永不作为默认目标。

Profile 含义：

- 隐蔽：容量较大、改动较轻、抗重编码能力最低。
- 均衡：默认选择，在容量和冗余之间折中。
- 鲁棒：三副本与更强 QIM，容量最低，适合预期存在轻度 JPEG 重编码的场景。

## 提取与验证

打开“提取与验证”Document，选择图片并先“检测”。可能状态包括未检测到支持的水印、检测到且可提取、需要密码、协议不支持、损坏不可恢复和认证失败。

输入密码后执行“提取并验证”。文本与 JSON 会显示有界预览；二进制只显示前 256 字节 Hex 摘要，完整内容必须显式导出。密码变化会立即清除旧恢复结果，避免把旧 Payload 当作新凭据的结果。V1 不包含数字签名，因此“来源真实性”固定显示未签名；完整性有效不等于能够证明作者身份。

## 安全与限制

“不可见”表示正常观看时不明显，不代表统计上无法检测，也不保证对裁剪、缩放、强降噪、截图、社交平台重压或掌握算法的主动移除者有效。工具不能恢复遗失密码。不要把机密只依赖于位置扰码；需要保密时必须启用密码保护。

Document 保存的是作业配方和源路径，不保存内联 Payload、密码或已恢复内容。输出图片本身仍包含 Payload；删除 Document 快照不会删除水印。
