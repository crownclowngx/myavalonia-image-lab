# G7 提取与验证 Document 记录

状态：完成（2026-08-30）

界面支持选择图片、检测、按需密码、提取验证、状态/置信度/ECC/完整性/真实性报告、有界 Payload 预览、取消和原子导出。文本/JSON 最多预览 4096 字符；二进制最多预览 256 字节 Hex。

快照 schema 1 只保存源路径。密码、恢复 Payload 与验证现场不持久化；恢复后必须重新检测。密码一旦变化，旧恢复缓冲区立即清零，导出按钮随之失效。失败状态不会保留上一次成功 Payload。

门禁证据：敏感快照、密码变化失效、Headless View、DI Scope 隔离和关闭清理测试通过。认证失败文案不区分错误密码与被修改图片。

偏差：没有原图参考时不显示 PSNR/SSIM；这属于计划中的可选能力。V1 不支持签名，报告诚实显示 `NotSigned`。
