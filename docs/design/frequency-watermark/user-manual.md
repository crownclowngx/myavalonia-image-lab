# 频域隐式水印新手使用说明书

## 先用一句话理解它

普通图片由很多带颜色的小方格（像素）组成。频域隐式水印会对图片中一部分不太显眼的变化规律做轻微调整，把一小段信息藏进去。正常观看时通常不容易注意到这些调整，但 ImageLab 可以按同一套规则把信息读回来。

这里的“水印”不是盖在图片角落的半透明文字。它更像写在图片内部的一张小纸条。纸条内容称为 **Payload**，可以是一段文字、JSON 或一个小文件。

## 第一次练习前准备

准备一张你有权处理的 PNG 或 JPEG 图片，另存一份副本。初次练习建议：

- 使用细节较丰富、尺寸不要太小的图片；大面积纯色图可用空间较少。
- Payload 先只写一句短文字，例如“ImageLab first test”。
- 输出选择新的文件名，不覆盖唯一原图。
- Profile 选择默认的“均衡”，暂时不启用密码。

## 五分钟完成一次写入

1. 打开“水印写入”Document。
2. 选择准备好的源图片。
3. 选择文本类型并输入短句。
4. 点击“估算容量”。容量可理解为这张图当前最多能安全放下多少数据。
5. 确认 Payload 没有超过容量，Profile 选择“均衡”。
6. 点击“写入并自检”。程序会先生成结果，再立即用正式提取流程检查一次。
7. 自检成功后，把结果保存为新的 PNG 文件。

如果提示容量不足，请缩短文字、换更大的图片或换有更多纹理的图片。程序不会偷偷截断内容，也不会在失败时修改源图。

## 把内容读回来

1. 打开“提取与验证”Document。
2. 选择刚才保存的输出图片。
3. 点击“检测”。检测只判断是否存在受支持的水印以及当前状态。
4. 点击“提取并验证”。成功后界面会显示文字预览和完整性结果。
5. 对二进制文件，界面只显示有限的十六进制预览；使用“导出 Payload”保存完整内容。

如果写入时设置了密码，提取时必须输入完全相同的密码。密码无法找回，也不会被保存在工作区快照里。

## 三种 Profile 怎么选

| Profile | 直观理解 | 适合情况 |
| --- | --- | --- |
| 隐蔽 | 改动更轻、可用容量较大，但更怕后续处理 | 图片基本保持原样，只做原格式保存 |
| 均衡 | 容量与耐受性折中 | 第一次使用和一般场景 |
| 鲁棒 | 重复保护更多、改动更强、容量更小 | 预计会经历轻度 JPEG 重编码 |

Profile 不是安全等级，也没有一种选择能保证抵抗裁剪、缩放、截图、强降噪或社交平台重压。

## 密码到底保护什么

启用密码后，Payload 会经过加密和认证。别人即使知道使用了 ImageLab，没有正确密码也不能正常恢复内容。密码不等于作者签名：成功解密说明内容和密码匹配，但不能证明图片一定来自某位作者。

请使用独立、足够长且可妥善保存的密码。关闭 Document 或恢复工作区后，需要重新输入密码。

## 常见状态怎么处理

- **未检测到支持的水印**：可能选错图片，或图片经过了水印无法承受的处理。
- **需要密码**：输入写入时的密码后再提取。
- **认证失败**：常见原因是密码错误或数据已损坏。
- **协议不支持**：图片可能由更新或不同版本的协议生成。
- **损坏不可恢复**：保护冗余也无法修复现有错误，尝试寻找更接近原始输出的副本。
- **容量不足**：缩小 Payload 或更换载体，不要依赖自动截断。

## 安全使用清单

- 保留原图和水印输出，不在唯一文件上实验。
- 需要保密时启用密码；不要把“看不见”当作加密。
- 对重要文件，写入后在“提取与验证”中亲自完成一次回读。
- 分享前如果平台会压缩图片，先用相同平台流程做副本测试。
- 不把水印结果当作数字签名、版权登记或来源证明。
