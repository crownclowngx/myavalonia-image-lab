# 频域隐式水印的数学原理

本文解释当前实现为什么能在图片中写入信息。阅读它不要求高等数学基础；公式用于准确说明关系，不是使用产品的前置条件。协议字段、加密参数和硬性上限以 [协议文档](protocol.md) 为准。

## 1. 从像素到亮度通道

彩色像素通常由红、绿、蓝三个数值表示。水印主要写入 Y（近似亮度）通道，而不是分别随意修改三种颜色。冻结的颜色换算保证写入和提取使用相同定义。直观上，人眼对不同形式的亮度变化敏感程度不同，把修改限制在选定的频率系数上，更容易控制可见影响。

透明度 Alpha 不参与水印计算，非完整 8×8 边缘也不承载数据。因此实际容量不仅取决于图片文件大小，还取决于可用块、透明区域和 Profile。

## 2. 8×8 DCT：把一个小块拆成变化模式

图片被分成 8×8 小块。对每个块做二维离散余弦变换（DCT）：

```text
C(u,v) = a(u)a(v) Σx Σy f(x,y)
         cos((2x+1)uπ/16) cos((2y+1)vπ/16)
```

`f(x,y)` 是块内像素，`C(u,v)` 是第 `(u,v)` 个频率系数。左上角 `(0,0)` 是 DC，代表块的平均水平；向右、向下通常表示变化越来越快。

水印不选最靠近 DC 的系数，因为修改它们容易影响整块明暗；也不依赖最末端的高频，因为压缩和降噪容易删除它们。V1 选择中频位置，在可见性和耐受性之间折中。逆 DCT（IDCT）把修改后的系数还原为像素。

## 3. QIM：用“落在哪一组刻度”表示 0 或 1

量化索引调制（QIM）可以想成两把交错的尺子。一把尺子的刻度代表 bit 0，另一把代表 bit 1。写入时，把选定 DCT 系数移动到目标尺子最近的刻度；读取时，看它离哪组刻度更近。

用简化形式表示，步长为 `Δ` 时，两组格点可写成：

```text
bit 0: kΔ
bit 1: kΔ + Δ/2
```

`Δ` 越大，两个集合分得越开，轻度扰动后仍较容易判断，但像素改动也可能更明显。Profile 会同时决定强度、冗余和容量，不能只把它理解为一个单独的步长滑块。

读取置信度来自系数到两个候选格点的相对距离。置信度高表示当前读数更偏向某一 bit，但它不是来源真实性的概率。

## 4. 为什么要扰码、重复和投票

如果连续 bit 永远写在相邻固定块中，局部裁切或损伤可能一次破坏完整字段。实现从协议随机材料稳定派生映射顺序，把符号分散到可用载体位置。

某些 Profile 会保存多个物理副本。提取时先按置信度进行投票，再交给纠错层：

```text
voted bit = argmax_b Σi confidence(i, b)
```

这解释了为什么物理副本已经出现 bit 错误时，投票后的数据仍可能正确。冗余会提高耐受性，也会按比例减少能装入的 Payload。

## 5. Reed–Solomon 纠错

Reed–Solomon（RS）把数据符号与额外校验符号一起编码。当前协议使用 RS(255,223)：完整块有 223 个数据符号和 32 个校验符号，最多能修复 16 个未知位置的错误符号；第 17 个可能超过纠错能力。

一般地，若码字长度为 `n`、数据长度为 `k`，校验符号数为 `n-k`，未知位置错误的理论修复上限是：

```text
t = floor((n-k)/2)
```

纠错不是无限恢复。损伤过大时，正确行为是明确失败，而不是输出看似合理但未经验证的内容。

## 6. 容量为什么需要先估算

粗略关系可以写成：

```text
可用 Payload ≈ 可用承载系数
               ÷ 每 bit 的副本数
               × 纠错编码率
               − Frame 固定开销
```

Frame 还要保存版本、类型、长度、安全材料和完整性信息；启用加密也有固定开销。因此“一张图有多少像素”不能直接等同于“能放多少字节”。程序按实际协议先规划容量，超过上限时整体拒绝，避免静默截断。

## 7. 加密、认证与水印检测是不同问题

- **加密**让没有密码的人难以读懂 Payload。
- **认证**检测密文、关键头信息或密码是否不匹配。
- **纠错**修复一定范围内的传输错误。
- **水印检测**判断图片中是否存在当前版本支持的结构。

这四层互相配合但不能互相替代。V1 没有数字签名，所以完整性有效只能说明内容通过当前 Frame 的验证，不能证明作者身份。

## 8. 质量与鲁棒性的根本取舍

更大的 QIM 间隔、更多副本和更多纠错通常提高恢复机会，却会降低容量，并可能增大可见改动。更轻的修改通常更隐蔽，却更容易被 JPEG、滤波或几何变换破坏。这不是实现缺陷，而是信息隐藏系统的基本权衡。

数学模型也不能保证所有图片表现一致。纯色、纹理、透明度、后续编码器和处理链都会改变实际结果，因此重要用途必须结合 [测试门禁](testing.md) 和具体样本实验。
