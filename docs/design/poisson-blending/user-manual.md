# 梯度域融合新手说明书

## 一次完整实验

1. 选择源图和目标图，然后点击“载入两图”。源图提供选择区域与梯度，目标图提供放置位置与边界颜色。
2. 在源图上设置矩形 `L/T/W/H`，或选择“添加/擦除”画笔后直接绘制。点击“应用遮罩”，检查未知量、连通分量、孔洞和边界数。
3. 输入整数 `dx/dy`，也可以在目标画布拖动轮廓；拖动结束后才提交像素偏移。点击“预检放置”。
4. 若出现 halo 越界或 Alpha 不是 255，请缩小/移动遮罩，或先把图片展平到不透明背景。程序不会自动裁切或展平。
5. 选择普通克隆、混合梯度或单色融合，点击“建立问题”。Build 只构造方程和初值，不会偷偷执行一轮迭代。
6. 点击“单步”观察一个完整红黑 sweep，或点击“运行”。“暂停”阻止下一轮，“取消”不会提交半轮或迟到结果。
7. 观察迭代数、RMS、MaxAbs、相对残差、热图和 log10 RMS 曲线。只有 RMS 与 MaxAbs 两个阈值同时满足才是“已收敛”。
8. 在并排视图比较左侧直接 Alpha 与右侧 Poisson。两者优化目标不同，界面不会宣称哪一个一定更好。
9. 已收敛且未过期时可导出 Poisson PNG、Alpha PNG、JSON 或 CSV 报告。

## 三种模式怎么选

- 普通克隆：迁移源内部 RGB 梯度，由目标边界决定整体颜色常量；可能出现整体色偏，这是算法语义。
- 混合梯度：每条边在源/目标整 RGB 梯度中选择更强者，可能保留目标纹理，也可能引入目标强边缘。
- 单色融合：只迁移源亮度细节，再把亮度差同量施加到目标 RGB，保留的是目标色彩倾向，不是绝对保色。

## 常见误解

- “收敛”不等于“自然”或“最佳”；它只描述离散方程残差。
- 直接 Alpha 不是错误算法，而是同位置、同遮罩的诚实基线。
- 半透明像素、软遮罩、旋转/缩放、自动抠图和图像配准不属于 V1。
