# 调色板与颜色迁移数学原理

## sRGB、XYZ D65 与 CIELAB

字节先归一化为 `c∈[0,1]`。sRGB 解码为：

```text
c_linear = c / 12.92                              c <= 0.04045
c_linear = ((c + 0.055) / 1.055)^2.4              其他
```

反向阈值为 0.0031308。线性 RGB 才能乘标准 sRGB/D65 矩阵。D65 白点固定为
`(0.95047, 1.00000, 1.08883)`，Lab 使用 `δ=6/29` 分段函数。V1 输入输出都为 sRGB D65，故不做白点适配。

## HSV 与 Hue N/A

H 为 `[0,360)` 度，S/V 为 `[0,1]`。当最大通道与最小通道差小于冻结 epsilon 时，Hue 状态为 Undefined。
Hue 直方图和 H-S 密度不把该样本放入 H=0；Hue 均值使用 Alpha 加权圆向量，而非普通算术平均。

## Alpha 加权统计

每个 `A>0` 像素的权重是 `w=A/255`，`A=0` 完全不参与。均值与总体方差使用加权在线更新，避免平方和减
均值平方的相消。有效像素数和有效权重分别报告。分位数由固定直方图近似，不常驻逐像素数组。

## 32³ 聚合与确定性 k-means

索引为 `r5<<10 | g5<<5 | b5`。cell 代表色是实际像素的加权 sRGB 均值。第一个中心取权重最大 cell；
后续取 `weight × nearestDistance²` 最大者；所有并列取较小 cell/cluster 索引。更新为加权 Lab 均值，
最大 64 轮，分配不变或最大中心移动小于 0.05 ΔE76 时收敛。

## 独立通道统计迁移

```text
mapped_c = μr_c + (x_c - μt_c) × σr_c / σt_c
result_c = x_c + strength × (mapped_c - x_c)
```

目标标准差小于 `1e-9` 时，映射值直接为参考均值；参考标准差为 0 时公式自然收敛到参考均值。
保留 L* 模式只对 a*/b* 使用公式。它忽略协方差和多峰结构，不是 Reinhard `lαβ` 或最优传输。

## 色域映射

Lab 反变换的线性 RGB 若出界，先将 L* 裁到 `[0,100]`，再保持 L* 和 hue，沿 chroma 在 `[0,C*]`
二分 24 次。逐通道 RGB clamp 会改变 hue 且隐藏损失，所以不使用。映射会改变理论统计，必须报告次数和 ΔE76。

## 最近色与色差

固定调色板分配使用平方 ΔE76：

```text
ΔE76² = ΔL*² + Δa*² + Δb*²
```

量化报告使用 CIEDE2000（`kL=kC=kH=1`），实现覆盖 hue wrap、零 chroma 和 Sharma/Wu/Dalal 公开参考对。
两者不能混称。ΔE00 汇总用 Alpha 权重固定 100-bin 近似 P50/P95，同时保留真实均值与最大值。

## Jensen–Shannon 直方图距离

对归一化的 L*/a*/b* 直方图，`M=(P+Q)/2`，返回
`sqrt(0.5 KL(P||M)+0.5 KL(Q||M))`。双方均为零的 bin 贡献 0。它描述分布距离，不是像素色差或图片语义相似度。
