# 调色板与颜色迁移新手说明书

## 最短流程

1. 在“目标图”选择 PNG/JPEG，点击“载入目标”；
2. 选择 K（2–12，默认 6），点击“分析颜色”；
3. 查看调色板、RGB 直方图、Lab a*-b* 密度和统计等价表格；
4. 若要颜色迁移，再选择并载入参考图，然后重新“分析颜色”；
5. 选择“完整 Lab”或“保留目标 L*”，设置强度并运行迁移；
6. 或选择目标/参考来源，冻结调色板，再执行固定调色板重映射；
7. 确认结果没有“过期”后导出 PNG、JSON 或 CSV。

载图不会自动分析，改参数不会自动对 16MP 图片反复运行。每次迁移和重映射都从原目标开始，不会把上次结果
继续累积处理。

## 三张图分别是什么

- **目标图**：必须提供；结果尺寸和 Alpha 都跟随它；
- **参考图**：颜色统计迁移需要；尺寸可以不同，不会被缩放或与目标逐像素对齐；
- **当前结果**：最近一次成功且与当前参数匹配的完整尺寸输出。

路径文本变化不等于已载入；请显式点击载入。保存并恢复 Document 后也必须重新选择/载入和运行。

## 主色与调色板

K 表示希望提取的主色数量。工具先把 RGB 各压成 5 bit，再在 Lab 空间做确定性 Alpha 加权聚类。
同一输入、K 和协议会得到稳定顺序与 fingerprint。

排序有三种：占比、L* 明度、HSV 色相。它只改变显示顺序，不改变 cluster 序号、fingerprint 或重映射结果。
“冻结”表示把当前来源的提取结果固定成一次可执行实验输入；换图或修改 K 后必须重新分析和冻结。

## 颜色统计迁移

“完整 Lab”匹配 L*、a*、b* 的均值和标准差；“保留目标 L*”只处理 a*/b*。强度 0 是原图逐字节副本，
1 是完整应用冻结公式，0.5 是原 Lab 与映射 Lab 的中点。

目标或参考单色时标准差可能为 0。工具采用明确的“收敛到参考均值”规则，不产生 NaN。
某些理论 Lab 结果超出 sRGB：工具保留 L* 与 hue，沿 chroma 二分压缩；这会使结果统计不能完美等于参考。

## 固定调色板重映射

每个 A>0 的目标像素与冻结调色板所有中心比较 ΔE76，取最近色；相等时选较小 cluster 序号。
输出 RGB 只来自调色板，Alpha 原字节保留。A=0 的隐藏 RGBA 四字节完全不动。V1 不加抖动。

## 怎样读数值

- 有效像素数：A>0 的像素数量；
- 有效 Alpha 权重：每个像素按 A/255 相加；
- Hue N/A：灰阶或极低饱和颜色没有可解释色相，绝不是红色；
- ΔE00：目标与结果的感知色差近似；均值、P50、P95、最大值同时显示；
- PSNR/SSIM：结果与原目标的全参考差异，不判断“更漂亮”；
- 色度压缩/L* 裁切：为写回 sRGB 而发生的色域映射；
- fingerprint：当前输入/配方或调色板的稳定身份，用来阻止过期结果导出。

图形都配有文字和等价表格，不需要只依靠颜色辨识。像素探针的目标和参考坐标分别输入；不同尺寸图片没有
隐含坐标对应关系。

## 导出与常见问题

PNG 始终为完整目标尺寸，并在内存中真实回读验证尺寸与 Alpha 后原子写入；不能覆盖目标输入。
JSON/CSV 不包含图片字节、绝对输入路径、用户名、机器名、临时目录或异常堆栈。

若提示“结果过期”，说明输入、K、冻结调色板、模式或强度在结果完成后改变，请重新运行。取消不会留下半结果；
关闭 Document 后迟到任务也不会写回 UI。
