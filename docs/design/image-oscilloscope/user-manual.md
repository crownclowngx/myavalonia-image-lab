# Image Oscilloscope 新手说明书

> 当前功能已作为第 21 个多实例 Document 接入插件和 Standalone；本说明书对应已实现的 V1。

## 这个工具是做什么的

图像示波器把一张图片里的所有像素换一种方式画出来。它不会修改照片，主要帮助你回答：

- 图片整体偏暗还是偏亮？
- 高光或阴影是否有很多像素挤在极端位置？
- 红、绿、蓝三个通道是否差异明显？
- 颜色是接近灰色，还是集中在某些鲜艳方向？
- 鼠标下这个像素在各种图表里落在哪里？

它展示的是数值事实，不会自动替你调色，也不会断言某种颜色一定是错误。

## 第一次使用

1. 新建“图像示波器”。
2. 选择一张图片，点击“分析”。
3. 看 Luma Waveform：大部分轨迹在上方表示亮值较多，在下方表示暗值较多。
4. 看 RGB Parade：红、绿、蓝分成三段，观察它们有没有某一段长期更高或贴边。
5. 看 Vectorscope：点越靠中心通常越接近灰色，越靠外通常颜色越强。
6. 打开高光/阴影覆盖层，看看警告像素位于画面的什么位置。
7. 把鼠标移到图片上，各图表会出现同一个像素的标记；点击可以固定这个点。

## 页面大致分区

- 顶部：选择图片、分析、取消、密度显示和裁切阈值；
- 左侧：原图、警告覆盖层和鼠标探针；
- 中间：Luma Waveform 与 RGB Parade；
- 右侧：Vectorscope 与 RGB/Y 直方图；
- 底部：饱和度、Hue、色度分布、平均色度和当前像素详情。

窗口较窄时，一些区域会进入 Tab，不代表分析结果被删除。

## 三个最重要的视图

### Luma Waveform

它保留图片从左到右的位置：

- 顶部代表亮，底部代表暗；
- 某处轨迹很亮，表示那里有很多像素落在相同亮度附近；
- 顶部或底部堆积可以提醒你检查高光和阴影。

### RGB Parade

它把红、绿、蓝分开画：

- 如果中性墙面上的三段高度接近，通常说明三个通道较平衡；
- 如果画面本来就是红花、蓝天或绿草，通道不平衡完全正常；
- 某个通道贴近 0 或 255，可以配合裁切计数继续检查。

### Vectorscope

它画的是颜色方向：

- 中心附近通常是灰、白、黑或低色度颜色；
- 离中心越远，通常颜色越强；
- 六个字母标记帮助认识红、洋红、蓝、青、绿、黄的大致方向；
- 点云偏向某个方向只说明图片内容偏向该颜色，不一定需要修正。

## 高光和阴影提示

默认把 0..5 视为阴影警告范围，把 250..255 视为高光警告范围。你可以查看亮度警告，也可以查看任一 RGB 通道警告。

这些提示的意思是“像素命中了阈值”，不是“相机原始数据一定损坏”。覆盖层只是显示标记，不会涂改照片。

## 鼠标联动

鼠标移到图片上时，你会看到：

- 这个点的坐标和 RGBA；
- 亮度、色度、饱和度和 Hue；
- Waveform 上一个点；
- Parade 上三个点；
- Vectorscope 上一个点；
- 直方图和颜色分布上的刻度。

如果颜色接近灰色，Hue 会显示 N/A，这是正常的：灰色没有稳定的色相角度。点击图片可以固定探针，方便把鼠标移开后继续读数。

## 常见误解

- “平均颜色向红”不一定是偏色，可能只是画面里有大面积红色物体；
- “高光警告很多”不一定表示拍摄失败，白色背景本来就可能接近 255；
- “Vectorscope 很靠外”不等于超过显示器色域；
- “RGB 三段不重合”不等于白平衡错误；
- 这里的示波器用于 8-bit 静态图片分析，不等同于 HDR 或广播视频工程仪表。

## 数据和隐私

V1 只在当前 Document 内存中保存源图和分析结果，不修改图片，也不提供上传、远程处理或批量目录功能。文档快照只保存视图设置、阈值和固定探针，不保存绝对文件路径、图片像素或 Scope 大数组。
