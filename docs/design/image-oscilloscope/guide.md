# Image Oscilloscope 使用指南

> 当前指南对应已实现的 V1。普通宽度下 Scope 按折叠分组展示；较窄窗口可滚动并折叠分组，数值结果不会因布局变化而重算。

## 最短分析流程

1. 新建“图像示波器”Document，选择一张静态图片。
2. 点击“分析”，等待 Luma Waveform、RGB Parade、Vectorscope 和直方图完成。
3. 先看 Waveform 的上下分布，再看 Parade 三通道是否在相似高度。
4. 查看 Vectorscope 点云离中心的距离和主要方向。
5. 打开高光/阴影覆盖层，核对阈值命中的具体画面位置。
6. 把鼠标移到源图，观察各 Scope 上的探针标记；点击可固定，再移动鼠标比较其他位置。
7. 查看饱和度、Hue、色度半径与平均 Cb/Cr，但不要把平均向量直接当成白平衡故障结论。

## 输入协议

- V1 只分析现有解码端口支持的 8-bit 静态图片；
- RGBA 固定在白色 sRGB 背景上合成，透明区域的隐藏 RGB 不进入统计；
- Scope 扫描全部源像素，源图显示代理只服务界面和探针；
- 分析不会修改、覆盖或另存源图片；
- 快照不保存文件路径，恢复后需要重新选择图片。

## 如何阅读各视图

### Luma Waveform

- 横轴对应图片从左到右的位置；
- 纵轴从底部 0 到顶部 255；
- 越亮的轨迹表示该位置和亮度组合的像素越多；
- 顶部大量堆积可能表示高光接近阈值，底部堆积可能表示阴影接近阈值；
- Waveform 使用 gamma-coded Y，不是传感器 RAW 或 HDR 真实亮度。

### RGB Parade

- 从左到右固定为 R、G、B 三段；
- 每段横轴仍对应原图横向位置，纵轴为对应通道的 0..255；
- 三段整体高度相近通常表示中性色区域较平衡，但彩色主体本来就会使通道不同；
- 某一通道贴近顶部或底部可能是单通道高光/阴影阈值命中；
- 三段共享密度量程，强弱可以直接比较。

### Vectorscope

- 中心表示低色度或中性；离中心越远通常色度越高；
- 右/上方向分别对应正 Cb/正 Cr；
- R、Mg、B、Cy、G、Yl 六个标记只是固定纯色坐标参考；
- 点云方向说明画面颜色内容倾向，不自动证明偏色；
- V1 不是 Rec.709 广播示波器，不显示 legal range、IRE 或 75% target。

### RGB/Y 直方图

- 横轴是 0..255，纵轴是像素计数或比例；
- 左侧峰多表示暗值多，右侧峰多表示亮值多；
- R/G/B 可以发现单通道分布差异，Y 反映固定亮度公式；
- 直方图没有空间位置，需与 Waveform 和覆盖层一起解释。

### 饱和度、Hue 与色度

- 饱和度分布使用 HSV S 的固定 0..1 量纲；
- Hue 只统计有定义的像素，并按饱和度加权，灰阶不会堆到红色 0°；
- 色度半径使用固定 Cb/Cr 量纲，不按每张图最大值自动拉伸；
- 平均 Cb/Cr 向量是全图颜色内容的均值，人物服装、天空、草地或背景都可能主导它。

## 高光和阴影警告

默认 shadow=5、highlight=250，边界包含阈值。可切换：

- Luma：按 Y 判断阴影与高光；
- RGB Any：任一 RGB 通道达到阈值即命中；
- Off：关闭源图覆盖层，但保留统计结果。

界面同时显示总命中数、比例和 R/G/B 各通道计数。覆盖层只是一层诊断显示，不改变源图片。阈值命中也不等于证明相机或前级处理已经不可恢复地裁切。

## 密度显示

- 默认“对数”适合同时看到稀疏与密集轨迹；
- “线性”更直接反映计数比例，但弱轨迹可能难以看见；
- 两种模式只重新投影现有精确计数，不重新分析图片；
- 最亮部分使用固定 P99.5 上限防止单一异常格压暗其余内容；
- 切换主题、窗口大小或 Tab 不应改变数值结果。

## 鼠标探针

### Hover

在源图内移动鼠标时显示：

- 源像素 x/y、原 Alpha 和白底合成后的 RGB；
- Y、Cb、Cr、HSV S/Hue（无定义时显示 N/A）；
- Waveform 的一个标记；
- Parade 的 R/G/B 三个标记；
- Vectorscope 的一个标记；
- 四直方图和三种颜色分布的 bin 标记。

Hover 不改变文档修订，也不会重新扫描全图。

### Pin

点击源图固定当前探针；再次点击其他位置更新，使用“清除探针”取消。固定坐标以归一化形式进入轻量快照，但源文件不进入快照。恢复后只有重新选择图片，固定探针才会在新分析上显示。

Scope 上移动鼠标可以查看密度格的坐标范围和精确计数；V1 不从一个 Scope 格反向列出或高亮全部源像素。

## 状态与错误

- “请选择图片”：尚无输入或快照恢复后需要重选；
- “分析中”：正在全图扫描，可取消；
- “结果已过期”：输入或影响主分析的协议已变化，需要重新分析；
- “裁切覆盖层更新中”：只重算阈值相关事实，其他 Scope 仍可查看；
- “操作已取消”：没有提交半成品，最后有效结果仍保留；
- “图片过大/资源超限”：在分配前结构化拒绝，不静默抽样或缩小冒充全图结果；
- “Hue N/A”：当前像素接近灰阶，Hue 没有稳定定义。

## 限制和正确表述

- 应说“在固定白底 sRGB/BT.601 协议下，平均色度向红方向偏移”，不说“图片白平衡一定错误”；
- 应说“有若干像素命中 250 高光阈值”，不说“传感器高光一定已裁切”；
- 应说“Vectorscope 点云离中心较远”，不说“颜色一定超出目标色域”；
- 应说“这是 8-bit 静态图片示波器”，不说“等同专业广播视频测量设备”。

V1 不做编辑、自动修复、视频、HDR、ICC、ROI、反向 Scope 选择或导出。这些能力若进入后续版本，需要单独冻结协议和门禁。
