# G0 产品、协议与质量基线记录

状态：完成（2026-08-30）

## 冻结结论

- 产品名称为“频域隐式水印”，只承诺感知上不明显，不宣称不可检测或抗主动移除。
- Host 贡献为两个 Persistable Document、零 Tool；稳定 ID 见 `PluginIds`。
- V1 使用 Y-only、8×8 DCT、中频四系数、QIM、公共控制信道与密钥映射数据信道。
- 签名不进入 V1；完整性与来源真实性在报告中分开，来源固定 `NotSigned`。
- 密码保护为显式可选；PBKDF2-HMAC-SHA256 600,000 次、AES-256-GCM。内联 Payload、密码和恢复内容不进入 Document 快照。
- 默认输出 PNG；JPEG 入口保留，但 UI 明确提示 PNG 更稳定。
- 上限：编码图片 64 MiB、16,000,000 像素、Payload 16 MiB、密码 1024 字符；差异/频谱预览最大边长 1024。

## 依赖决策

生产插件不新增私有图片或密码学 NuGet：图片使用 Host 共享 Avalonia 12，密码学使用 .NET BCL，RS(255,223) 为项目内纯托管实现。`Avalonia.Skia` 只属于 Tests 的 Headless 正式编解码后端，不进入插件交付依赖。

## 威胁模型

覆盖偶然 bit 损坏、轻度 JPEG 重编码、小噪声、错误密码、恶意 Header 长度和随机图片误报。V1 不承诺对裁剪、缩放、旋转、截图、强滤波、平台重压或掌握算法的主动攻击保持恢复。

## 偏差与延期

开发回归使用确定性纹理与真实 PNG/JPEG 编码字节。授权照片大语料、发布设备性能、真实 Host、ZIP 和 Windows CI 按用户要求延期，不能据此写市场级质量承诺。

回滚：首次发布前可调整 Profile 或 Protocol；发布后必须增加版本，不能改写 V1 含义。
