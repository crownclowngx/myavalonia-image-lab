# 图像比较实验室用户指南

## 它解决什么问题

图像比较实验室对两张**解码后尺寸完全相同**的 PNG/JPEG 做逐坐标全参考比较。第一张固定称为参考图，第二张称为
待比较图；所有有符号变化都按“待比较 − 参考”计算。它比较的是解码后的未预乘 RGBA8888 像素，不比较文件字节、
扩展名、EXIF 或编码参数，也不会自动判断图片“合格”或“篡改”。

## 基本流程

1. 打开“图像比较实验室”，分别选择参考图和待比较图。
2. 点击“比较”。应用顺序解码两张图，再执行完整像素指标、六通道直方图和有界显示投影。
3. 尺寸不同时，底部会显示两边尺寸和宽高差；此时没有指标、像素对应、差异图或直方图，不会静默缩放或裁切。
4. 尺寸相同时，在并排、分割、叠加、闪烁、RGB 差异和热力图之间切换。切换模式不会重新扫描完整图片。
5. 通过滚轮缩放、右键拖动平移；“适应”使用当前面板，“100%”表示显示代理像素 1:1。两幅图共享中心和缩放。
6. 在视口移动指针读取对应原图像素；也可在右侧输入原图 x/y 后点击“检查”。
7. 点击“复制摘要”获得人类可读文本，或“导出 JSON”得到 schema 1 报告。导出使用原子写入。

“交换”会真正交换参考/待比较角色并重新比较。因此 PSNR、SSIM 和绝对误差不变，但像素报告的 Δ 符号会反向。
任一路径发生变化时，旧 Session、摘要、复制和导出资格立即失效。

## 六种视觉模式

- **并排**：左右面板共享视口和准线。
- **分割**：左侧参考、右侧待比较，分割比例可用滑块或键盘调整。
- **叠加**：参考图在下，待比较图按 0–100% 透明度覆盖。
- **闪烁**：同一位置交替显示两图。默认暂停，间隔限制为 250–2000 ms；闪烁可能引起视觉不适。
- **RGB 差异**：显示 `clamp(|Candidate-Reference| × 倍率, 0, 255)`，Alpha 固定 255。
- **热力图**：MaxRGB 或亮度绝对差异使用固定 256 色表；颜色不随单张图片自动归一化。

差异倍率只支持 1、2、4、8、16、32。底部投影说明中的“饱和像素”是 1024 最大边代理上的计数，不是原图计数。

## 指标如何解释

- `PSNR-Y`：完整图片 Y 通道 MSE 的峰值信噪比，单位 dB；零误差显示 `∞`。
- `PSNR-RGB`：R/G/B 共 `3N` 个样本的 PSNR。
- `全局 SSIM-Y`：使用整图 Y 均值、样本方差与协方差，不是常见 11×11 滑窗 SSIM Map 平均。
- `MSE/MAE/RMSE/最大差异`：完整 RGB 样本误差。
- `变化像素比例`：至少一个 RGB 字节不同的像素数除以总像素数。
- `Alpha`：不进入颜色指标，而是单独报告 MAE、最大差异和变化像素。

完全透明像素中的 RGB 字节仍参与 RGB/Y/Cb/Cr 计算。因此可能出现肉眼不可见区域有颜色差异，或仅 Alpha 不同时
颜色 PSNR 为 `∞`、但 Alpha 变化数不为零。这是明确的 V1 语义，不是遗漏。

## 直方图与像素差异的区别

R/G/B 直接进入 0–255 bin；Y/Cb/Cr 使用项目冻结公式后四舍五入并裁切。蓝线是参考图、橙线是待比较图；
`log10(count+1)` 只改变显示纵轴，不改变原始计数。直方图只描述边际分布：两张像素排列完全不同的图也可能拥有
相同直方图，所以必须结合空间差异、像素报告和全局 SSIM-Y 理解。

## JSON 与隐私

schema 1 输出稳定英文 camelCase 字段、算法标识 `image-compare-v1`、文件名、尺寸、指标和原始直方图计数。
`∞` PSNR 使用 `{ "value": null, "isInfinite": true }`，因此 JSON 始终合法。默认不写绝对路径、图片像素、
缩略图、水印 Payload、异常堆栈或操作系统用户目录。

## 明确边界

V1 不包含对齐、缩放、裁切、旋转、局部 SSIM、MS-SSIM、Delta E、边缘/纹理指标、批量比较和行业无关阈值。
这些能力必须先单独冻结变换记录、精度基准、数据集与性能预算，不能从当前结果推导。
