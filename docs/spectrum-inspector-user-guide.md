# 频域分析器用户指南

## 能做什么

“频域分析器”是 ImageLab 的第三个 Persistable Document。每个实例独立保存图片路径、通道、分析档位、
显示模式、频带和最后选择的原图坐标，适合并排比较不同图片或参数。V1 只分析受控尺寸的代理，不把代理
结果伪装成原尺寸处理结果。

## 基本流程

1. 打开“频域分析器”，选择 PNG 或 JPEG 图片。
2. 选择 `R/G/B/Y/Cb/Cr` 通道和 `512/1024/2048` 最大边档位。
3. 点击“分析”。状态栏会同时显示原图、分析代理和补零 FFT 尺寸。
4. 在频谱面板切换线性幅度、对数幅度、P99.5 百分位幅度、相位或分块 DCT。
5. 将指针移到频谱上，侧栏显示中心化坐标、内部 FFT 索引、cycles/pixel、半径、幅值、相位和能量。
6. 点击原图预览，侧栏显示对应完整 8×8 块的通道像素、DCT 系数、IDCT 重建和最大误差。
7. 选择全部、低频、中频、高频或自定义环带。连续参数变化有约 150 ms 防抖，只有最后结果会提交。
8. 重建有效后可导出 PNG。导出尺寸是分析代理尺寸，状态栏会再次明确这一点。

## 数值含义

- 频谱中心是 DC；`fx/fy` 单位为 cycles/pixel。
- 默认低频为 `0 < ρ ≤ 0.15`，中频为 `0.15 < ρ ≤ 0.50`，高频为 `0.50 < ρ ≤ 1`；DC 单列。
- 低频遮罩包含 DC；中频和高频不包含 DC。
- 相位只有在幅值高于相对阈值时有意义，零能量点显示“未定义”。
- 径向曲线固定为 256 bin；侧栏给出 DC/低/中/高频占总能量的比例。
- 全部频带使用逐字节短路，不做无意义的 YCbCr 往返；其他频带使用共轭对称 0/1 遮罩和 IFFT。

## 通道与透明度

- RGB 重建只替换选中颜色字节；另外两个颜色字节和 Alpha 保持。
- Y/Cb/Cr 重建保留另外两个原始色彩分量，逆变换超界时裁切并报告发生裁切的像素数。
- Alpha 从不进入 FFT。透明像素仍按解码后的未预乘 RGB 分析，这一点也显示在界面说明中。

## 资源、取消与恢复

- 小图不会被放大；大图使用面积平均抗混叠缩小。
- 宽高分别补到不小于代理尺寸的最小 2 的幂，单个复数缓冲不超过 `2048×2048`。
- 新图片、新通道或新档位会取消并清除旧会话；显示模式和悬停不会重新执行 FFT。
- 关闭 Document 会取消分析、重建和能量刷新。迟到结果由 generation 门禁拒绝。
- 快照不保存像素、Bitmap、复数频谱或重建 PNG；恢复后必须显式点击“分析”。

## V1 不包含

任意频谱画笔、陷波、Butterworth/Gaussian、原尺寸实时 FFT、批处理、频谱写字、水印载荷地图和任意
原图尺寸导出均不在 V1。Windows CI、ZIP、真实 Host 和正式发布也不属于当前开发阶段。
